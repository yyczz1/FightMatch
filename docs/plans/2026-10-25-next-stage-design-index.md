## 4. 已定边界与尚需用户介入的事项

已定路线继续使用：uGUI运行时／UI Toolkit编辑器、英与简中、Luban、YooAsset、R2、Go＋sqlc＋MySQL、AdMob单广告源、游客首发、Android7最低系统。Unity2022.3继续使用，2022.3.62f3只是发行准备评估候选，不据此自动升级。

首章范围是1—16关；盾骑士21关、弓箭手37关以及后续章节不并入首章完成承诺。正式账号绑定／邮箱登录、云存档／人工找回、当前战局在线分析保留设计方向，首版暂缓实施。

目前没有阻止计划编写的用户待答题。真正涉及新产品选择时集中提出具体方案；资源服务开通／预算、发行地区及发布账号／凭据、最终美术采用与设备人工操作在对应阶段处理。不会为了写计划先购买服务。

美术继续占位可支撑功能设计和接入开发。现有战士待机初选不等于所有动作已验收或已导入；主美独立管理资源选择、动作完整性、授权和导入规格，只有跨组依赖影响里程碑时汇报中央。

## 5. 后续实现的约束

- 保留分层＋QFramework＋项目自有uGUI控制器，不以这次架构说明为由更换框架或重写全部代码。
- 每个功能有一个业务入口、明确的状态归属、失败恢复路径和人工可读的调用说明；正常分行与命名，避免新增巨型Host或构建方法。
- 只在具体功能触及职责混杂处时作必要提取，不做全仓Candidate重命名或追求形式上的接口层数。
- 测试先复用有效证据；新增检查对应新增行为或改变的风险。设计说明不算测试通过，作者声明不算独立审查。
- 普通工作由各组负责人直接分发、纠正和收件。新源码独审仍交GitHub PR Code Review；本轮计划不另开本地R审查或云测试运行。

本阶段完成标准是上述计划有实际代码／既定策划依据、具体输出与顺序、依赖和延后边界，并与版本日志一起保存。它是下一阶段设计工作的起点，不宣称每项详细设计或正式安卓首版已完成。
