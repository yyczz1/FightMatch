## 已确定的完整产品规则

- 首章方向为童话玩具城中的“发条庭院＋发条熊王”，每 16 关一个 Boss。起始战士；法师第 8 关通关后入队，盾骑士21、弓箭手37；这是完整内容方向，不能直接扩入当前仅 L1 的发布集合。
- 第一张通用职业证在**首次进入16的战前**赠送一次，玩家确认战士嘲讽学习并看完保护法师说明后开战；15为普通复习，取消独立练习。Lv5条件、手动用卡/用证与教学跨重进保持，整场首通再给第二枚。旧14/15二选一已被覆盖。
- Boss 第一面棋盘完整完成后翻面；两面属于一场战斗和一次整关结算，HP/CD/状态/物品/PRD/历史按规则延续。双方全灭仍可免费补完剩余线，第一面完成先翻面再判断救援，最终面完成判胜。
- 死亡不自动挤掉原队列空位；范围技能按原站位规则处理。具体作用顺序、贡献评分、绕线恢复、成长边界以正式配表与系统契约为准，不拿旧火球系数候选或示意代替当前输入。
- 默认完整攻略免费、可反复查看；广告解锁本次挑战的联网当前局面分析及约定后续更新。线上输出必须经同一战斗规则验证，不能改动真实局面。已得权益不会因退出被撤销；SDK/云服务未接时显示真实不可用，不模拟成功。
- 广告机会正常使用仍算已用；回退/重来撤销对应 UseId 使用时恢复原机会一次，退出不清掉未用机会。未用通关机会可在原关后续合法尝试使用，包括新挑战，不重复旧尝试奖励。进行中战斗不跨设备同步，细节见架构入口与后续权益/云同步契约。

G01 资源不足、返旧关练级再回教学的有限见证已归档。旧算例14XP使W到5级加6XP描述的是该历史校准模型，不可与正式 Demo L1 的 baseXP20 混用。旧 R02“主策划仍待归档”已由主回复 H 与 integration-review §19 闭合；不再次向用户提同一问题。更完整的平衡、全组合验证和真实试玩仍须按各自证据说明，普通关15秒/Boss60秒是体验目标，非设备实测保证。
