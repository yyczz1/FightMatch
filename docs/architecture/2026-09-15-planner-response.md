**1．专属技能与 CD**

**已定，有用户依据：**

- 一次有效连线提交一次玩家行动，之后推进敌方阶段；不设行动点、不强制换人。
- 不另设主动技能按钮，已解锁职业技能随连线按规则生效。
- 战士嘲讽本次连线对应的单个目标，技能不限距离，攻击仍受射程限制。
- 嘲讽覆盖紧接着的一个敌方阶段，阶段结束到期；盾骑士群体护盾也覆盖这个阶段。
- 攻击不可达而技能可达时，可以只施放技能。

依据：[行动规则](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:39)、[射程与技能](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:79)、[嘲讽与护盾](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:105)。

**未决：** 当前会话与两份文档中，没有找到已确认的技能冷却规则。“嘲讽持续一个阶段”是持续时间，不能直接解释成 CD。架构任务转来的“主动技能有 CD”需要按新输入继续细化，也不能据此增加技能按钮。

**建议及代价：**

- CD 按**全队有效行动**推进：完整完成一次玩家行动及其敌方阶段，推进一次。双射、毒伤等子效果不多推进；思考、无效画线、广告与菜单操作不推进。
- 新战斗技能初始可用；重来恢复入场状态。
- 新施放技能不在施放自己的这一轮立即扣一次冷却。用“还需经过多少次后续有效行动”定义 CD，避免差一回合。
- 例如战士施放后还有 `K` 次冷却，换法师完成一次行动及敌方阶段后变为 `K−1`。这里 `K` 不是已定数值。
- 冷却期间，若攻击也不可达，则端点不能提交；若攻击可达，就正常普攻。UI 应区分“技能冷却”和“技能距离不足”。
- 代价是玩家换其他角色也能让战士技能恢复，需要平衡护盾、嘲讽的覆盖率；好处是不用为了刷新技能反复操作同一角色。

**2．被动触发、双射与 PRD**

**已定：** 战士概率暴击、弓箭手概率双射、盾骑士概率格挡；不同角色、不同被动分别积累伪随机机会；重演相同行动保持一致，撤销不能重抽。没有确定正式概率，早期 50% 是例子。

**未决：** 各自判定单位、双射连锁、第二发暴击、毒箭消耗、PRD 生命周期，均未定。文档明确保留了这些缺口。[依据](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:117)、[道具触发缺口](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-gameplay-followup.md:60)。

建议先形成下面这份触发约定，全部待确认：

| 效果 | 建议判定单位 | 边界 |
|---|---|---|
| 暴击 | 每次实际执行、具有暴击资格的直接攻击 | 仅技能行动、毒跳伤不抽取；没有暴击能力的角色不会因此获得暴击 |
| 双射 | 一次普攻的第一发完成后，目标仍存活时判定一次 | 第二发不再判双射；第一发已击杀则不执行第二发，也不扣第二发道具 |
| 格挡 | 每次符合格挡条件的直接受击 | 物理、法术的适用范围还要明确；建议首版不中毒格挡 |
| 毒箭消耗 | 每支实际作为毒箭射出的箭 | 双射最多消耗两支；只剩一支时，第二发按普通箭处理 |

第二发可以参加普通伤害、暴击和道具结算，**前提是角色确实具有对应能力**；禁止它再次生成额外攻击。毒伤等状态伤害不触发双射或再次施毒。这样靠明确触发来源终止连锁，而不是事后截断一个已经无限递归的流程。

“目标已有中毒时还要不要使用毒箭”仍需要单独定义，不能从上表推导。建议在毒效果方案确认后，一并决定刷新、叠加和消耗条件。

PRD 生命周期建议：

- 新战斗重新初始化。
- 死亡、广告复活保留本场积累；广告本身不抽取随机结果。
- 撤销、重来恢复对应快照中的随机状态与积累。
- 普通战术物品换装不清空角色固有被动积累。

这些生命周期规则尚未确认。每关重置容易理解，但短关中 PRD 的连续补偿效果会更弱，这是需要实测的代价。

**3．首版职业与技能解锁节奏**

**已经可以直接补进表格，不必重问：**

| 职业 | 已有依据 |
|---|---|
| 战士 | 近距离物理输出；默认被动概率暴击；专属技能单体不限距离嘲讽 |
| 盾骑士 | 生存较强、物理输出较低；默认被动概率格挡；专属技能为存活队友加盾 |
| 法师 | 法术输出，适合处理高物防敌人 |
| 弓箭手 | 远程物理输出；默认被动概率双射 |

每名角色默认一个被动；**5 级＋职业之证解锁专属技能**；首个新职业目标在第 10 关，首个 Boss 目标在第 16 关。[职业依据](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:96)、[解锁节奏](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:198)。

**仍未决：**

- 初始三职业、关卡 10 解锁谁。
- 法师被动与专属技能、弓箭手专属技能。
- 首个 Boss 前是否提供职业之证。
- 各技能数值、射程、CD。
- 一个职业是否允许拥有多个角色实例。

没有更晚的用户决定补全这些内容。早期“法术穿透能杀高物防怪”的描述是克制体验例子，不足以确认法师必有某种固定穿透技能。目录中的卷轴、破甲箭等同样只是演示内容。

**建议：** 先用“战士＋法师＋盾骑士开局，第 10 关解锁弓箭手”作为首版草案。若希望首 Boss 前教会保护配合，应安排提前获得职业之证与达到 5 级的可靠途径；否则前 15 关和首 Boss 都必须不依赖专属技能。

提前发证会改变“职业之证仅由 Boss 提供”的原始节奏，需要用户确认。若教学需要嘲讽和群盾同时存在，还要保证两次解锁资源，不能只发一枚证却假定两人都解锁。

**4．属性、等级与敌人配置**

**已定的属性或行为维度：**

- 三名队员各自拥有生命、攻击、防御、等级和职业能力。
- 物理、法术输出存在差异，高物防敌人应体现职业克制。
- 攻击射程、技能射程分别判断。
- 暴击、双射、格挡存在概率效果。
- 敌人有类型、排列位置、射程、行动频率、目标选择和特殊能力。
- 存活队员进入下一关满血；倒下者不能因此自动复活。
- 打怪收益战斗内待结算、胜利后统一结算，已有规则不要求战斗中即时升级。

依据：[属性与敌人](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:75)、[恢复规则](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:139)。

**未决：** 没有正式等级属性表、伤害公式、暴击倍率、格挡减伤量、升级生命增长规则或敌人数值档表。敌人的物理/法术防御字段如何组织也未定；“能体现高物防克制”不等于已经批准具体公式。

你提出的以下组织方式，我支持作为**待确认的内容配置方案**：

| 表 | 建议职责 |
|---|---|
| 职业＋等级属性行 | 该职业在该等级的基础属性 |
| 技能/被动配置 | 解锁要求、效果、射程、概率、CD、触发条件 |
| 敌人类型 | 行为、伤害类型、合法目标规则与特殊能力 |
| 敌人数值档 | 生命、输出、防御等固定数值组合 |
| 关卡敌人实例 | 引用敌人类型和数值档，指定顺序与关卡行为参数 |

同类敌人在不同关卡引用不同数值档，可减少逐只填数值的不一致；代价是需要清楚管理档位。**目前没有敌人随玩家等级缩放的用户依据，应保持关卡敌人配置固定。**

数值公式建议先检验物理、法术各自的比例减伤方案；简单的攻击减防御容易让低攻角色长期只能打最低伤害。公式和系数仍需确认与验证。

升级生命建议只在局外结算，倒下者仍保持倒下状态，避免升级变成未经讨论的免费复活；进入下一关时沿用已确认的存活者满血规则。

**5．一次行动的顺序，尤其是毒与固化线**

**已有依据的顺序只有这个层级：**

> 完成合法连线 → 结算该角色的攻击/技能及反馈 → 推进敌方阶段 → 嘲讽、群盾在约定阶段末到期 → 下一次选择。

直接击杀保留这次线路，未击杀线路消失；敌人死亡后更新存活顺序。精确的普攻、道具、被动、技能、毒伤和死亡检查之间的顺序尚未确认。[依据](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:43)。

**建议先形成可验证的候选顺序：**

1. 校验目标、路径及可用攻击/技能，保存行动前状态。
2. 执行普攻中的实际攻击；每次处理适用道具、伤害型被动、减伤与生命变化。
3. 每次实际攻击后检查死亡；死亡目标不再接受双射第二发等后续攻击。
4. 执行仍满足条件的非伤害职业技能。
5. 确定本次目标死亡结果与线路固化；若已清场，进入胜利处理。
6. 推进敌人行动时机，执行到时且仍存活的敌人行为。
7. 处理约定的阶段末效果、状态到期和 CD，生成下一轮可见意图。

这只是针对当前已知技能的草案；未来“强化本次攻击”的技能需要明确列为攻击前效果，不能所有技能都被塞到同一个后置位置。

在这套候选顺序下，**普攻击杀目标后，单体嘲讽因目标死亡取消，不进入 CD**；群盾的受益目标是存活队友，条件仍成立时可以执行。这里的取消与是否进入 CD 都属于待确认细化，当前文档不能直接得出答案。

**毒是最需要先处理的缺口。**

- 毒在敌方行动前还是后结算，未定。
- 毒能否杀死敌人，未定。
- 毒在后续行动杀死敌人时，应固化哪条线，未定。
- 不能回头直接固化最初施毒的路线：那条未击杀路线已经消失，沿途可能被后来其他固化线占据。
- 不能默认“毒死就不留线”：这改变了当前击杀占格规则，也会改变解谜难度。

**我的首版建议：毒箭先采用同一次连线内结算的毒性附伤，将脱离连线致死的敌人持续毒伤留待后续。** 代价是首版毒箭没有持续磨血玩法。毒蛇对队员施加持续毒伤可以单独讨论，因为队员死亡不涉及棋盘路线归属。

若用户坚持敌人可以被后续毒伤杀死，就必须专门决定占格规则；不能由求解器或架构自行选择。持续毒伤若保留，我倾向阶段末结算，降低同一阶段内意图被打断的复杂度，但这同样未定。

**6—9．第二批缺口与建议顺序**

| 项目 | 已定与缺口 | 建议 |
|---|---|---|
| **6．全灭与失败返还** | 全灭仍可广告复活继续；失败/退出/重来恢复入场道具数量、收益不保留。未区分“全灭等待选择”和“结束尝试”。 | 全灭时保留本次消耗与战况，等待复活或放弃；选择退出、重来等真正结束尝试后执行返还。否则全灭时先返还、复活继续又保留效果，容易造成重复资源。属于需要记录的结算边界消歧，不必重问“失败是否返还”。 |
| **7．广告通关收益与死者** | 正常胜利、正常奖励与解锁、不削收益已定；评分替代基准、真实统计、死者结算未定。 | 为参与队员建立正常通关经验基准，奖励至少保留其已获得的真实评分收益；可研究“真实收益与正常基准取高”。统计只展示真实行为，补足部分进入通关经验，不伪造伤害。由于评分无硬上限，有限基准无法等价所有可能的正常收益，要明确“正常基准”的定义。死者处理优先沿用普通胜利规则，不能默认广告顺便全队复活。 |
| **8．广告、回退与提示权益** | 完整历史回退、同关重开可重新查看已获得攻略、有效攻略提供前不扣权益已定。跨广告复活的回退，以及重打/偏离攻略的计次未定。 | 将已看广告获得的权益与可回退的战斗效果分开。回退撤掉某次复活时，可恢复那一次复活的使用资格，避免要求重复看广告；同一权益不能同时留下两次有效复活。重来时资格如何保留还需明确。提示建议一次挑战有一次免费分析，重来不刷新；通关后重打算新挑战，偏离已获攻略的新分析再使用后续权益。此整套计次仍待确认。 |
| **9．同职业多人及道具草案** | 是否允许同职业多实例尚未回答；职业专属、每人一叠、最多 99、现有库存自动补充已定。 | 先解决角色实例规则，再决定是否存在同物品补给竞争。若允许多人争同库存，可按出战位顺序优先补满并显示分配结果，代价是后位可能拿不到；平均分配是另一种玩法，不应暗选。首版道具/配方草案由策划先提出，架构只反馈字段和执行条件的缺口；现有 24 配方演示不转成内容表。 |

对应依据：[失败与恢复](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:127)、[提示与广告通关](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:170)、[消耗结算](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:217)、[目录示例边界](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-gameplay-followup.md:49)。

第二批推荐顺序：**全灭结算边界 → 广告复活与回退权益 → 广告通关经验/死者 → 提示计次 → 多实例补给与正式配方。** 多实例问题可沿用本任务已经提出、尚未收到回答的问法，避免两边重复询问。

**最值得先让用户回答的三个具体问题**

以下供架构任务组织下一轮，**不是我在本轮另向用户发问**：

1. **技能 CD 是否在其他队员出手后也推进，入场是否直接可用？**
   推荐：全队每次有效行动推进，初始可用，施放当次不自减；冷却期间只能技能可达的目标不能提交。

2. **首版毒箭是否需要在后续回合独立毒死敌人？**
   推荐：先采用同次连线内的毒性附伤，保持击杀路线有明确归属。若必须持续毒死，先确定占格变化，再设计结算与求解。

3. **双射是否只追加一发，第二发如何参与暴击和消耗？**
   推荐：不再触发双射；具有暴击资格时正常判暴击；实际射出的毒箭逐支消耗，第一发击杀则取消第二发。

这三项会直接改变同一行动的结果与可用操作，应先于完整数值填表确定；已有职业定位、五级解锁、射程、持续阶段、评分方式及消耗返还规则可以直接补全到规格中，无需重开讨论。
