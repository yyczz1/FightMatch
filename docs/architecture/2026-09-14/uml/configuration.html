12 · 职业等级属性、敌人数值与关卡配置

ConfigSystem 为客户端提供指定版本的只读 ConfigCatalog。职业等级行给出升级后的属性；敌人类型与数值档分开，关卡为每个颜色配对选择具体敌人和数值档。

逻辑表结构与类均为候选，未创建配置资产。每级 HP、攻击、防御等真实数值待策划填表；不默认让敌人随玩家等级缩放。技能、物品、配方、升级经验、掉落等完整目录见对齐清单。

ConfigSystem --> ConfigCatalog : 加载与校验后提供
ConfigCatalog --> ProfessionDefinition : 按职业 ID 查询
ConfigCatalog --> EnemyDefinition : 按敌人类型查询
ConfigCatalog --> EncounterDefinition : 按关卡 ID 查询
ProfessionDefinition --> HeroLevelStatsRow : 按属性表 ID 和等级查询
EnemyDefinition --> EnemyStatsRow : 同类型可有多个数值档
EncounterDefinition "1" *-- "1..*" EncounterEnemyEntry : 固定敌人组
EncounterEnemyEntry --> EnemyStatsRow : 选择本关实际数值档
CombatStatBuilder ..> HeroLevelStatsRow : 角色入场属性
CombatStatBuilder ..> EnemyStatsRow : 敌人入场属性
note for ConfigCatalog "还包含技能、状态、物品、配方、成长经验和掉落；完整字段目录见对齐清单"
note for CombatStatBuilder "当前生命、PRD 与 CD 写入独立对局，配置本身保持只读"
