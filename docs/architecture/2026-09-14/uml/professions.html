05 · 职业配置与技能行为

保留连线自动施放。SkillResolver 检查技能可用性，再由具体效果判断是否适用：战士击杀目标后跳过嘲讽、不启动新 CD；盾骑士仍按存活队友条件放盾。

CanApply 与 Resolve 是已有技能效果接口的候选职责，不增加另一套自动战斗系统。其他职业的技能条件以后由策划分别讨论，不统一套用战士的跳过规则。

ProfessionDefinition --> SkillDefinition : 被动与职业技能配置
SkillResolver ..> SkillDefinition : 读取分类与效果参数
SkillResolver ..> ISkillEffect : 按效果类型选择实现
ISkillEffect <|.. DamageEffect
ISkillEffect <|.. TauntEffect
ISkillEffect <|.. ShieldEffect
CombatStatBuilder ..> ProfessionDefinition : 按职业和等级读取属性表
BattleRules ..> SkillResolver : 统一检查触发和执行效果
note for TauntEffect "本次目标已被攻击击杀则跳过，不启动新 CD"
note for ShieldEffect "按存活队友判断；不因本次击杀目标而跳过"

候选类与代表性方法，用于讨论职责；除 Existing 类型外，均未实施。可用原始尺寸检查细节。
