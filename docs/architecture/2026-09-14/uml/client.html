01 · QFramework 与战斗规则如何连接

客户端仍由 QFramework 组织。Command 调用 BattleSystem，BattleSystem 直接调用普通 C# 的 BattleSession；结果再以事件交给表现层。

BattleModel 只持有当前对局，不另外保存一份生命、状态或路线。PlayerModel 持有局外存档数据。图中方法只说明职责，不是已批准的公共 API。

class BattleController {
  <<Unity>>
  SubmitCompletedPath()
  PresentOutcome()
}
class SubmitBattleActionCommand {
  <<QFramework>>
  Execute()
}
class BattleSystem {
  <<QFramework>>
  StartBattle()
  SubmitAction()
  RewindTo()
}
class BattleModel {
  <<QFramework>>
  BattleSession currentSession
}
class PlayerModel {
  <<QFramework>>
  PlayerState player
}
class BattleSession {
  <<PureCSharp>>
  ApplyAction()
  RewindTo()
}
class BattleOutcome {
  orderedEvents
  battleResult
}
BattleController ..> SubmitBattleActionCommand : 发送
SubmitBattleActionCommand ..> BattleSystem : 调用
BattleSystem --> BattleModel : 获取当前对局
BattleSystem --> PlayerModel : 开战读取局外数据
BattleModel "1" *-- "0..1" BattleSession : 唯一当前实例
BattleSystem ..> BattleSession : 直接调用
BattleSession ..> BattleOutcome : 返回
BattleSystem ..> BattleOutcome : 发布事件
BattleController ..> BattleOutcome : 订阅并播放

候选类与代表性方法，用于讨论职责；除 Existing 类型外，均未实施。可用原始尺寸检查细节。
