## 3. R02 的架构解释与交接

依据：[主策划](../../game-design/2026-09-14-fightmatch-game-design.md)第03／08／09节及PRD生命周期，[三组规则](../../game-design/2026-09-15-three-group-recommendations.md)“撤销与广告复活”“全灭、补线与两面Boss”。直接条款是从头重新开始本局、永久资料与真实时间不回退、PRD恢复入场状态、本次消耗在重来时恢复，以及原本恢复中的选中角色不参战。

SD00核对后采用以下设计解释，不把它描述为用户逐字段作过决定：

1. 立即重来创建新AttemptId，保留同ChallengeId及原EntryBaseline；原尝试结束、新尝试和物品冻结移交一致提交。不是加载一份旧玩家总存档。
2. 回整关第一面，恢复原参战集合、槽位、属性、HP和战斗随机／PRD初态；第二面不是新检查点。清掉旧尝试进度、战斗消耗与待结算贡献，无失败收益。
3. 本次战斗倒下不先生成阻塞重开的局外恢复，也不把入场初始化HP记作一次广告使用；广告机会是否恢复仍由R01单独决定。
4. 原本未参战的恢复中角色继续其真实恢复进程。即使恢复已到期，也不能被原基线重来加入参战集合；界面应显示最新恢复状态，不能从旧EntryData伪造仍在倒计时。
5. 已领首证、已确认用卡／学习／用途说明和晚到永久经验保留。新尝试读取原战斗基线，不追改入场属性；永久Model仍是最新已提交版本。
6. 退出地图是另一条结束路径：最终倒下者交接局外恢复，之后普通入场读取最新成长、恢复、阵容和定义，遵守正常开战条件。
7. 重复重来只返回原操作结果；提交未知先查结果，不能再次建新尝试、发物或初始化恢复。表现读取新AttemptId及修订，旧门闩不能解锁新场。

职责交接：M03提供长期资料及原基线参与者的已算属性，M06从固定基线重建战斗，M04移交冻结数量，M08按R01只处理准确UseId，M02／M07组织一次提交。没有一个Module可以恢复整份旧永久资料。H02／H06与A04按此解释收敛，R01以第6节用户后续原则及精确撤回关系为准。

## 4. 曾交用户的两个选择（历史推荐，已由第6节覆盖）

### R01 推荐B：立即重来恢复，直接退出不恢复

旧尝试内每条仍有效的局内复活使用被撤回，对应角色机会各恢复可用一次；原广告完成事实保留。已经被回退撤销的使用不再次增加机会；新尝试的活角色不会因此被额外治疗。连续重来没有新使用就不会增加次数；旧u1不能释放后来u2。先前结束尝试及局外恢复使用不批量重置。

这使直接重来与先撤销使用再重来一致，但允许放弃全部旧进度后在后续重试再次使用同一次广告机会。直接退出保持当时的使用状态；先撤销使用再退出仍沿用已定回退能力，两条退出路径可以不同。备选是直接重来和直接退出均保持已用，并接受其与先撤销路径不同。

### R03 推荐：同关同挑战手动兑现，目标已完成不补奖

保留原请求的关卡、ChallengeId、发起AttemptId和完成事实；资格可暂存到换关之后，但只在原关、同一未完成挑战的合法尝试中由玩家明确使用一次。不得自动切关、自动通关或跳过16教学／成员可出战条件。

实际使用B时，以B的参战者、绑定配置和真实消耗结算；不复开A，不追扣A已返物品，不同时发A奖励。换了阵容、等级、配置或消耗，收益也可能与看广告时不同。正常胜利已经提交为WonPendingSettlement时优先完成正常结算，不能改成广告经验。

原挑战已正常或通过其他合法方式胜利时，标记“目标已完成”并关联胜利结算；不伪造此资格曾被使用，不额外补奖，不转成复活／货币／倍率，也不能留到同关下一次挑战。另一项自愿结算增益仍需独立选择并关联真实SettlementId。备选为仅原尝试有效、关闭后失效且不补偿；若用户另提补偿，需明确范围后再设计。

## 6. 用户决定：已获得的广告权益都不回收

用户在本会话明确说：“只要是看过的广告，对应的广告权益都不回收”，并询问是否足以回答两项问题。SD00接收为统一权益原则，原二选一不再待答；不是将策划旧推荐整包视为获批。此处“看过”沿用已完成广告并获得对应权益的含义，不改变未完成／未核验广告的接入规则。

**用户明确决定的内容：** 已获得且未兑现的权益不能因回退、重来、退出、换关、关闭页面、回执迟到或原挑战已经通关而被删除、过期或标成无效。广告事实与已发永久收益一直保留。旧方案“目标已完成所以未用机会失效”不再成立。

**结合既有一次使用规则的系统设计解释：** 正常使用不是回收。一次性机会已经实际兑现，记录为已使用；效果被正式撤销，撤回对应UseId并恢复同一机会一次。角色再次死亡不等于撤销此前复活，不能因此免费复用。已发卡／经验不因战斗撤销减少，卡后来被玩家正常用掉也不是广告权益遭回收。

| 用途／场景 | 本次落到系统设计的规则 |
| --- | --- |
| R01 回退／立即重来 | 回退跨过复活使用，或立即重来舍弃旧尝试全部战斗历史时，撤回旧尝试相应有效UseId，机会恢复一次。新尝试初始化HP不额外消费或增加机会，已撤回u1不能释放后来u2。 |
| R01 正常退出／再次死亡 | 未用或已经撤回的机会保留；退出本身不是删除资格的原因。正常退出按当前最终存亡交接，既有已生效使用仍记已用，不自动把退出变成一次历史撤销；后续再次死亡也不重复免费兑现。这是保留“正常使用”和“没收”的区别，并非所有广告变为无限次服务。 |
| R03 原尝试退出／重来／原关已通关 | 未兑现的通关机会保留为原LevelId的一次手动资格；可以暂存并用于同关后续合法尝试，包括新的ChallengeId。旧AttemptId／ChallengeId保留作来源，不再充当过期条件；不转成别关、货币或复活。 |
| R03 实际使用 | 玩家在合法尝试B明确使用，按B参战者、绑定配置、实际消耗及广告基础经验结算一次；确认前显示目标与效果。教学／可出战条件仍生效，不复开已结算A、不多发其首通奖励。正常胜利已形成时先完成正常结算，尚未使用的机会继续保留。 |
| 结算增益／资源 | 按原SettlementId或原报价继续兑现；换页、跨天或换关不抹掉已得资格。已发收益不重发，已正常消费的资源不自动补回。 |
| 在线攻略 | 已获得内容持续可看，失败保留未交付服务并可重试；原挑战关闭不能销毁尚未交付的资格。已实际交付的服务按原服务范围记录，不能从本原则擅自推导无限次跨关分析；SD07／SD09细化交付记录与续用交接。 |

后两列具体对象和完成点属于架构对新原则的落实，不冒称用户逐字段批准。尤其退出仍须区分“结束并保留当前实际效果”和“撤销该效果”，不能既保留已兑现效果又无条件增加一次机会。若后续策划要求改变一次性用途或服务范围，应按新要求更新，不能把旧失效规则偷偷加回。
