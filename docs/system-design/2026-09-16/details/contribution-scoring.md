## 4. 实际量与评分去重

对一次已由M06定义好口径的受击，R为进入格挡／盾／HP分段的可分解生命点量；B为本次实际格挡减免、S为实际盾吸收、H为真实扣HP、O为剩余溢出。
要求`R=B+S+H+O`且各项非负，H不超过该段发生前实际HP；R不能直接拿未完成护甲／属性修正的敌人基攻替代。各段顺序和伤害floor由原战斗规则给出，M07不另定。
O不计攻击伤害或承伤评分；未消耗的盾容量、空治疗、尸体反馈均不计。B／S也只取原规则证明的实际量，不能用名义技能值或剩余容量。
对多来源同时DOT，继承同批前HP及逐来源精确cᵢ，核`Σcᵢ=真实扣血`；盾前后份额有已定依据才接纳，不在M07重分盾或逐来源floor。

| 本轮原试调项目／权重 | 受益与实际依据 |
| --- | --- |
| 有效生命伤害×1 | 原攻击／状态施加来源；普攻、火球、DOT分别保留目标和效果段。克制已在实际量中，不再次乘分。 |
| 盾吸收×1、治疗×1 | 原盾生成者／原治疗来源；只计本次S／真实治疗效果增加的HP。复活、下一关满血和敌方上弦均不计玩家治疗分，不以HP差额单独构造治疗事件；旧模型未启用不等于未来无需来源。 |
| 格挡减免×1/2 | 实际格挡者的B；只接原绑定允许的攻击类型，不把毒跳伤改成可格挡。 |
| HP承伤×1/4 | 实际被击中角色的H；不计盾吸收与溢出。 |
| 束缚取消攻击×1/2 | 原控制来源及被取消的准确攻击，采用绑定规定的该次减伤前量；空放、免疫、无攻击意图为有依据的0。 |
| 首章有效嘲讽×1/2 | 原嘲讽来源、确实改变目标的远程攻击及其基攻；已瞄自身、蓄力／休息无有效改目标不计。不能外推为任意控制公式。 |

这些是[内容交接§4](../../../game-design/balance/2026-09-19-calibration-inputs.md#4-评分事件交接)沿用的试调权重，绑定必须明确实际采用项；不把本稿当全职业权重已正式发布。
每一原受击与受益角色形成一组：嘲讽分T和该角色承伤分P并存时取`max(T,P)`；只有一项则取该项。先逐组处理，再与其他项目相加。
同一角色另一次受击的P仍累计；同一攻击不同受益角色不互相抑制。格挡与盾属于已分解的其他实际量，不因本条被统统放入max，也不把整场嘲讽和承伤只取一次最大。
权重后的总贡献C保持精确有理值且不设玩法上限；M07导出值只作为该报告的评分依据，不能与M06事实分别维护可改的两本贡献账。
同类刷新来源与已知单盾比例吸收按共同r11／计划r30接为下一轮离线联合校准口径，仍非正式发布或旧用户原答；M07只收M06给出的确定来源及分段。多段盾覆盖／消耗次序仍排除，不给刷新动作新增辅助分。

## 5. 精确评分与整数出口

M07以原报告角色r的入场等级Lᵣ、推荐等级Lrec、精确贡献Cᵣ及原整关参考贡献J求值；不同角色各自计算，不共享固定经验池，不以最后一击分配。
当前N2-S固定样本的参考是整关初始敌HP总和÷2；已有全部面都在原定义内，敌方恢复不修改J。正式消费者读取绑定的参考定义，不能固定写死2或重算当前存活敌HP。
本轮曲线为`Sᵣ=0.5+0.5×log₂(1+Cᵣ/J)`，等级修正`Gᵣ=(3/4)^max(0,Lᵣ−Lrec−1)`，正常基础经验`Bᵣ=floor(E×Gᵣ×Sᵣ)`，J>0、E为非负整数。
以上常数来自原config及交付修订，零贡献在此候选得到曲线起点0.5；不是本稿另批准的永久保底。绑定若未给合法零贡献策略、参数或范围，拒绝受影响计算。
实际量、权重乘积、Cᵣ、J和等级修正保持精确；不先将Cᵣ取整，不对log₂显示数求floor，不用epsilon。UI精度只影响显示。
log₂及乘积必须使用原Numeric已证明的出口能力：传播上下界到最终表达式，只有floor一致才固定Bᵣ；精确幂边界按该能力处理，跨界或资源不足不能猜中点。
[数值研究§5](../../2026-09-17/numeric-random-research.md#5-log₂-的最少确定方向)与本次240个样本仅提供设计／有限证明；本稿不选择整数宽度、运行时库、正式Numeric版本或任意输入的迭代上限。
G01的两个log₂输入是3、37/12，二者平方均>8且立方均<32，因此`45/8×(1+log₂x)`严格位于`(225/16,15)`，两口径floor均14；这是该见证的手工证明。
M07给[成长M03](character-growth.md#4-经验卡耗与属性算法)准确非负整数向量，M03按当前永久成长加固定量并跨级；当前成长影响升级结果，不反向改变入场评分。
