来源引用必须在该尝试的原记录中可解析；不以列表位置、当前行动角色、同职业缩写或换一个OperationId补出未知受益者。
本轮刷新来源沿效果稿联合校准：同类可比较强度更强则替换强度与伤害来源，弱／同强仅刷新次数并保留来源，另记刷新者；来源倒下不重指，刷新不新增分。本文只接上游确定的本时点适用结果，不将候选套入旧绑定。
dᵢ=0须有完整依据。已知单盾由上游按效果稿§5将同批修正且floor后的qᵢ按比例吸收，交精确盾后dᵢ；零总量不除零。未知多盾覆盖／消耗顺序、盾来源不明或逐来源依据缺失才返回BLOCKED及准确缺项，不暗选毒／烧伤优先或把多盾伪装单盾。
绑定未知交UnsupportedBinding；上下文过时交StaleContext；非法数值、来源重复／缺失或覆盖不完整均返回具体拒绝／缺口，完整候选不生效。
纯计算接收不可变值，只返回贡献结果及核对依据；不访问UI、存档、网络、长期角色或背包，不抽随机、不发经验、不另生成操作身份。

## 3. 精确份额与不变量

先在输入中剔除“批前已经死亡目标”的执行资格：该目标本批真实扣血和新增贡献均为0，不产生第二次死亡。
对合法活目标，令D=Σdᵢ；空的完整来源集合与全零集合均为D=0，令A=0、所有cᵢ=0，不做除法。
D>0时，真实扣血A=min(H,D)，剩余HP为H−A，每来源有效贡献为cᵢ=A×dᵢ/D。
同目标各来源共用这一个H、D、A；先得全向量，再按原受益CharacterId精确相加，最后加入原累计，不能先合并成一名“击杀者”。

| 性质 | 文档证明 |
| --- | --- |
| 非负与单项范围 | A、dᵢ、D非负且D>0，故cᵢ≥0；A≤D，故cᵢ≤dᵢ，零伤害来源得0。 |
| 守恒与HP封顶 | Σcᵢ=A×Σdᵢ/D=A≤H；真实扣血只发生一次，溢出D−A不进入任何角色贡献。 |
| 排列无关 | 精确求和的D及按原来源关联的dᵢ不因排列改变；每个原来源的cᵢ相同，角色汇总也相同。 |
| 无溢出 | D≤H时A=D，逐项cᵢ=dᵢ；不为了比例分配削减本来真实发生的伤害。 |
| 精确非整数 | H=1、d=(1,2)时D=3、A=1，c=(1/3,2/3)；两项相加为1，不是显示值0.33＋0.67的反算。 |

本文采用数学上的约分整数比n/q、q>0描述精确值；零规范为0/1。原精确十进制／整数比直接进入该描述，不先转float再声称还原。
乘、除、求和及角色累计均保持精确有理值；约分不改变结果，不逐项floor、不分配余数、不加epsilon；显示格式可以变化但不反写状态。
这只是本子范围的表示要求，不选择正式NumericContractVersion、整数宽度、序列化编码或依赖库，也不声称任意累计已经能装入long。
[数值研究r1](../../2026-09-17/numeric-random-research.md)§4仍缺输入域、分母增长、乘积宽度及资源上界证明。超出已证明能力时报告数值能力缺口并停止该候选；不得降精度、环绕、静默截断或减少可回退历史。
真实贡献不增加玩法硬上限；运行／发布须由后续Numeric设计提供精确表示与资源失败证据，能力未证明不能把本文的数学证明当运行通过。

## 4. M06候选与H10交接

M02先按原OperationId和意图查询已成结果；同ID异意图拒绝，旧操作已被回退则返回历史结果及Superseded，不重新累加。
新合法操作由M06读取同一完整当前局面；先完成H04中DOT之前的步骤，再冻结统一DOT输入，各目标分别计算完整向量。
目标本批H>0且H−A=0时形成一次死亡事实；全场DOT结果齐备后按原规则处理死亡和存活敌人行动，不让动画或目标遍历提前移除其他目标的本批输入。
贡献变化与对应HP变化、死亡、状态计次、其余整轮变化、历史锚点及新SceneRevision共同构成一个TransitionResult；本函数不私自推进状态计次或PRD。
M06核对逐来源份额和角色增量合计等于对应真实扣血，累计等于旧值加本次增量，所有来源仍能沿原记录核验；数值及覆盖任一失败均无完整成功候选。
M02按[应用流程r1](application-flow.md)§4收齐同头候选、未变切片、原绑定引用与OperationResult，再交M12；不能单独保存贡献后另存HP或让M07监听动画发奖。
H10确认持久后一次发布完整新局面，M01才表现；源份额可供核对和显示，但UI没有修改权，动画完成不再次加贡献。

| 断点 | 持久结果与续办 |
| --- | --- |
| 计算中或SaveFailed | 原完整HP／贡献／历史仍有效；未成候选不发布，原意图沿原操作办理。 |
| CommitUnknown | 依M02现行未划安全分区策略冻结该玩家写入，先查原提交；不能换ID重算并提交第二份。 |
| 已成而回执／动画丢失 | 返回原操作结果，从最新完整头重建显示，不重扣HP或重加贡献；当前已到更晚头时不回装原O快照。 |

## 5. 历史、报告与既有消费者

[战斗历史r1](battle-history.md)§2／6的完整贡献包含本批精确来源份额、受益关系及累计；回退与HP、状态、完整随机／PRD一起恢复到合法操作边界。
回退产生新SceneRevision，保留原操作记录；旧回调不能重新施加被撤去贡献。重演同绑定、完整状态及ActionConditions，按同来源得到相同精确份额。
玩家回退后主动改变输入仍按新合法操作处理，不把不同偏好产生的变化误判为数值不确定；免费补线／翻面／等待不追加DOT或贡献。
最终FinalAttemptReport按原Attempt和绑定封闭，携同一精确贡献与受益关联、实际消耗及报告指纹；不能由结算页面从展示数字重建。
M07读取报告的原精确贡献并按绑定评分契约产生经验；本包不定义贡献权重或log₂，只继承正常经验最终floor的既有出口，不能提前把贡献变整数。
[成长r3](character-growth.md)§4／5只接M07固定整数经验向量，M03不重算DOT、评分或入场基础属性；倒下／复活不把来源改归当前行动者。
广告直接通关仍给真实入场参与者基础经验、不套评分；保留已有真实统计且不补造后半场贡献。[结算r1](settlement.md)的原8固定e／q和Deferred／Applied不因本规则重算。
已有尝试、历史及已成奖励保持原绑定与原结果；恢复缺原能力时交原恢复门处理，不把新比例实现或当前包静默套到旧结果。
