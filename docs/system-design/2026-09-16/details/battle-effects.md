## 3. 一次行动与固定槽火球

1. M06在行动开始锁定主目标原槽和左右槽；按原规则完成攻击形式／消耗、每发普攻与允许的被动、实际HP和命中状态。
2. 到法师自动技能阶段，再核已学、CD及合法射程条件；原槽集合不因普攻死亡、固化或活敌序号变化而重选。
3. 中心已死时只处理集合内仍有效的邻位，不转移中心系数；固定空槽不跳过找更远者，边缘不绕回。
4. 三个固定槽均无有效目标则不施放、不启动新CD；否则为一次施放，各有效目标分别取中心或邻位系数。
5. 各目标形成直接伤害及其后合法命中状态；不同目标结果均保留来源。死亡目标不制造后续烧伤伤害、额外击杀分或新的普攻。
6. 自动技能完成后，以统一时点冻结全场应结DOT目标／来源，再按§5形成所有结果；结果齐后统一处理这批死亡与存活敌人行动。
7. 原旧CD在回合结束减少，新施放CD2当轮仍2；后续两次完整有效行动后才为1、0。阶段盾等按原期限到期，未吸收部分不计贡献。
8. 当前整轮全部完成后有待补线先AwaitLinks；补完才攻击、翻面或最终胜利。免费补线／翻面不推进DOT、CD、PRD，也不再次执行死亡伤害。

普攻已杀本次连线目标，按原规则固化该线；火球／DOT杀死的非连线目标列入待补PairId，不恢复已消失的旧临时线。
全场DOT开始时已死亡者不再扣HP／盾或产贡献；同一时点内某来源角色倒下不删除其他已经确定的本批输入，不因播放顺序改变同归于尽结果。
范围内活目标但直接火伤免疫，不等于目标死亡；具体技能是否可施加其他效果须已有适用条件。本章直接火伤系数明确1.0，此泛用情况不以猜值放行。

## 4. 每目标伤害分段及溢出

下一离线候选明确采用r=入场已算魔攻×中心或邻位系数，m=r×100/(100+目标法防)×直接火伤修正×已有易伤，q=floor(m)；保留r、m及各修正依据，再进入盾／HP分段。
仅最终floor，无中间floor、不加最低1或epsilon；火球不继承普攻穿透、不额外暴击，成长、火修正与当前易伤各用一次。魔攻、法防及倍率须为合法非负输入，不能给未知敌人补默认。
来源为N1已经采用且本次增列实读的[boss_model.py](../../../game-design/balance/boss_model.py)第19～20行damage函数，以及config第95行所有修正后floor、587～588行0.8／0.4候选；此非正式Numeric选择，不再等待完整火球回放才确定该候选求值。
手工对照：魔攻27.28、火修正／已有易伤均明确为1，法防15时中心1.0得floor(2728/115)=23、0.8得floor(10912/575)=18；法防0时邻位0.6得floor(2046/125)=16、0.4得floor(1364/125)=10，均NOT RUN。
未知目标防御、适用火修正或易伤仍报其实际缺项，不从这四个结果反推或补值；已给输入可直接沿该式比较两组成对倍率，局部对照不冒称整场或正式跨端能力通过。
本章逐敌表可直接采用：机械金属、直接火伤1.0、毒／烧伤免疫、闪避0，保留原双防及核心易伤。直接伤害仍结算，不为免疫状态索取缺少的烧伤系数。

对合法活目标单次直接火球，单盾量B、批前HP H：吸收s=min(B,q)，实际扣HP a=min(H,q−s)，溢出o=q−s−a；余盾B−s、余HP H−a。
须有q=s+a+o，所有量非负；直接火球没有物理格挡分段。来源伤害贡献只计a，盾保护事实只计s，o与未用盾都不计真实贡献。
一般受击沿原规则提供的可分解来伤R、实际格挡避免量g，再到盾／HP；记录R=g+s+a+o。本稿不规定格挡比例或另加一次floor。
例如R=17、g=4、s=8、H=2，则a=2、o=3；不能将盾后5全算HP承伤，也不能丢溢出后宣称17=14。
目标原本已死时不消费盾、制造新HP损失或死亡；表现溢出与规则的原来伤／真实量明确区分，不从伤害动画补记录。

## 5. 异常刷新与单盾DOT

### 同类状态：本次联合采纳的校准规则

| 已有状态与合法新施加 | 同类结果 |
| --- | --- |
| 无活动同类状态 | 建立新强度、伤害来源／受益关系及规定剩余次数；原施加与首次可跳时点一并保留。 |
| 新强度大于原强度 | 用新强度及新伤害来源替换，次数重置为该状态规定次数；记录本次施加／刷新者。 |
| 新强度小于或等于原强度 | 保留原强度、伤害来源及受益关系，只重置次数并记录刷新者；不因同强度后来命中转走贡献。 |
| 原伤害来源已经倒下 | 已存在且仍应生效的状态继续归原来源，不重指当前行动角色；状态是否仍有效由原目标／期限决定。 |

毒与烧伤分别持有状态，不叠同类层；毒重置3次、烧伤2次。刷新本身不新增辅助分，不推翻合法毒箭对已中毒活目标仍消耗的规则。
采用施加时已算、可比较的来源强度；本次刷新只比较同类型、同单位及同一比较阶段的值。强度不是已包含当前目标全部修正的展示跳字。
目标侧适用修正按每跳原规则应用；毒不再走物防／法防，烧伤按自身火伤配置，弱点对一跳只算一次。未来临时属性增益规则不在本包扩展。
玩家本轮新施加／刷新在紧接的统一时点可跳；毒3跳完首次余2、烧伤2跳完首次余1。敌方阶段新施加等下一个统一时点，不能回插已完成的DOT阶段。
次数按实际发生的规定结算时点推进，不以是否击穿护盾作为额外续期；因明确免疫而未建立的状态不伪造跳次。目标后来适用性变化须有原规则依据。
泛用烧伤需要合法施加条件及强度输入；未给系数时不发明每跳值。明确免疫的首章分支记录不施加即可，不能因此删除泛用DOT能力。

### 一个已知来源盾：先吸收，再分实际HP

对同一活目标，从统一批前状态取得HP H、可用单盾B及本批全部已确定qᵢ。qᵢ已过原修正和伤害floor，不因列表次序先抢盾。
明确无盾时B=0且无盾生成者，不为零吸收伪造来源；非零盾余额来源不明不能冒充无盾。
令Q=Σqᵢ；Q=0时S、各sᵢ／dᵢ／cᵢ和本批扣HP均0，不除零且不消费盾。
Q>0时S=min(B,Q)，每来源吸收sᵢ=S×qᵢ/Q，盾后生命伤害依据dᵢ=qᵢ−sᵢ，D=Σdᵢ=Q−S。
D>0时复用[DOT贡献稿](dot-contribution.md)的A=min(H,D)、cᵢ=A×dᵢ/D；D=0时A=0且全部cᵢ=0。
每来源溢出oᵢ=dᵢ−cᵢ；故qᵢ=sᵢ+cᵢ+oᵢ，Σsᵢ=S、Σcᵢ=A，余盾B−S、余HP H−A，死亡最多一次。
所有份额保持精确整数比，不对sᵢ或dᵢ再floor；盾归其原生成者的实际吸收S，DOT来源只获cᵢ。同角色多来源先保留逐项证据再汇总。
HP5、盾3、q=(4,6)：s=(6/5,9/5)，d=(14/5,21/5)，c=(2,3)，o=(4/5,6/5)。两个分配阶段都与来源排列无关。
若改成盾优先吸毒3，会得d=(1,6)、c=(5/7,30/7)；该反例说明本次盾分配是明确采纳的新校准口径，并非旧HP比例条款自然包含。
仅接受一个已知来源的盾；多段盾叠加／覆盖／消耗顺序、来源不明的余额盾均返回具体缺口，不合并成伪造单盾，也不将吸收归给当前行动者。
