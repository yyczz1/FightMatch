## 1. 唯一职责与完成范围

M05维护S10开放／首通／教学／一次赠证和S11挑战关系。M03拥有角色、经验与技能，M04拥有物品及准确来源，M06拥有实际尝试，M07拥有结束与固定奖励，M08拥有广告资格，M09拥有攻略交付；M05只给这些操作所需的进度依据。
M02组织用户请求和候选，M07组织结算候选，M12完成H10持久交付。M05不能直接发证、扣证、加经验、创建战斗或销毁广告资格；它也不保存第二份技能已学或当前战斗阶段。
目标是让调用方只凭只读进度／约束和候选即可完成入场、教学、通关与恢复；不暴露一串可被UI任意调用的“标已领／标已学／标通关”写操作。
验收为第10节七项文档见证，真实游戏、存档和云端测试均NOT RUN。以下数据名和Interface表达业务语义，不要求新增同名C#类型或公开API。

## 3. 对外Interface

| 能力 | 输入与只读结果／候选 | 完成和错误语义 |
| --- | --- | --- |
| 查询进度与待办 | PlayerId、关卡／教学范围、当前已提交版本、M10可用定义；返回开放、首通、未完成步骤、挑战和原依据 | 查询不创建Challenge、不赠证、不自动完成步骤。缺定义返回具体不可用原因，不清事实。 |
| 核对入场与学习约束 | LevelId或学习目标、ContentBinding／DefinitionBinding、M03当前角色／可用成员、M04库存及原首证结果、相关修订 | 返回EntryAllowed、TeachingRequired、Locked、NoReadyMember或准确成本用途约束；不是冻结物品或承诺稍后自动执行。 |
| 提出进度候选 | 稳定OperationId、原输入指纹、预期CommitId／StateRevision、明确事件／步骤／目标及参与负责者证明 | 返回不可变S10/S11候选、发生事件及关联要求；M02／M07合并其他负责者候选后H10完成才发布。 |
| 核对恢复／检查点 | 准确已提交版本、必要M03／M04／M06／M07结果和原绑定 | 返回一致性证明或具体RecoveryBlocked／ReconciliationRequired；不按最高等级或卡余额推断历史。 |

组织者先查原操作：同意图已完成返回原结果，同ID异意图拒绝；新操作再检查预期版本。读取后的角色升级、库存变化、教学推进或本机头变化使原预览过时，不能静默采用另一成本／步骤。
M05对输入证明只做所拥有规则的核对，不绕过负责者。M03判定是否达到Lv.5及真实已学；M04判合法成本；M06／M07判是否形成合法整关结束，不接受UI直接传来的“已胜利”。
各候选可包含同次学习或恢复完成后的状态依据，避免强制先发布半份状态。组织者必须证明候选来自同一基线及同一操作，不能把上次预览和本次库存拼接。
返回业务Completed必须含原OperationId、受影响关卡／步骤／挑战、新修订及CommitId；仅建立候选、外部许可成功或下载完成均不是进度完成。

## 4. 开放、教学与入场判定

按已发布ProgressEvent及其有限事件语义形成开放事实；使用明确LevelId、事件类型和绑定，不按显示名或“最高关卡＋1”猜所有前置。未给出的章节／配方不由M05生成。
关卡开放与开战分开：开放但16教学未完成返回TeachingRequired；普通已开放关卡不因推荐等级不足或道具为0被M05锁住。关卡资源不可用由M10／M14交回取得或兼容问题，不能伪装玩家尚未解锁。
M02确认当前没有另一活动尝试、无未完成本机基础结算，M03核对当前可用成员，M05核对开放和教学，M04才生成携带冻结。M07源已成结果在目标分支的Deferred不属于此阻断，B可正常回刷／推进前置；一个前置失败均不提前开战或冻结。
对16入场请求，先找到／建立其未完成Challenge，再办理必要教学；已有Challenge不等于已有Attempt。教学界面不产生战斗实体，未结束教学仍可返回地图／队伍和正常旧关。
恢复中的选中角色保留槽位，实际可用成员由M03给出；至少一人可出战才能H02。M05不自行替换成员，不把低于推荐等级误报NoReadyMember。
首次进入16的赠证属于入场请求的独立持久步骤，父流程若跨多个确认使用稳定子OperationId；离开页面不撤销已完成赠证，之后的新进入请求仍受业务onceKey防重。
教学完成后，M02重新读取当前角色、物品、约束和整关绑定，再构造H02；不能沿用教学前旧属性或把“说明已确认”当成尝试已创建。普通准备与Boss演出由M01/M02在业务完成后衔接。

## 5. 第16关教学与首证用途

用户已确认“教学完成前为战士保留首证”。它仍为通用ItemId，只通过准确Level16EntryGift赠物引用限制用途；其他合法取得的证可用于其他角色，不能把整类通用证禁用。
教学状态显示由已提交步骤及当前缺口派生；实现只保存必要事实，不同时维护一个可独立改写的阶段枚举。下表是便于调用方理解的阶段名称。

| 派生阶段／输入 | 允许请求与下一结果 | 联合完成依据 |
| --- | --- | --- |
| 未领首证 | 合法首次进入16触发赠第一枚；不以重复查询触发 | M05记录Level16EntryGift及结果引用，M04加1通用证并关联准确端点，同次H10。 |
| 已领，战士未达学习条件 | 显示等级／经验／合法证成本缺口，可返回、培养或刷旧关 | 领取事实与首证用途保留；未确认培养不扣卡，不自动学技能。 |
| 已领，战士可学 | 玩家确认战士嘲讽；M03检查等级／技能，M04选受限首证作为这次合法成本 | 扣准确首证、技能已学、教学学习步骤完成及操作结果同次H10。 |
| 已学，尚未确认用途说明 | 展示既定说明并允许玩家确认；不能再次扣证或再次学习 | M05核M03已学证明后提交说明步骤；动画结束不是玩家确认。 |
| 教学完成 | 返回可继续入场，重复进入不强制重播已完成教学 | M05完成事实与M03已学一致，M02重读H02；不会重新发首证。 |

“首证1、其他证0、法师Lv.6”在普通菜单确认学习：M05返回首证用途限制及其当前依据，M04可花成本0，M03不产生学习候选；显示总数1不能成为可扣1的证明。返回与回刷仍允许。
“首证1、其他独立合法证1、法师Lv.6”允许普通学习选择另一枚证，首证仍保留给战士；扣普通证与法师学习同次提交，不推进战士教学步骤。M04须证明实际成本不是那枚首证。
战士已经通过一次合法明确学习获得嘲讽时，M05可核对该结果完成学习步骤，不能要求再学再扣；仍要完成未读用途说明。若首证尚未消费，其限制持续至教学完成，然后同一库存不加量地解除用途约束。
首证已因合法战士学习消耗后，说明完成不返还这枚证。限制的终止只改变合法用途判断，不创造第二次赠物、可用计数或战斗冻结转出。
过时的教学依据不能批准普通学习：预览后教学／赠物／库存变更，确认返回StaleContext；所有入口由M02统一向M05／M03／M04核对，页面入口不能决定是否启用限制。
已完成学习不追溯撤销；若旧档／跨档带来“首证已给其他角色且战士未学”的非兼容状态，保留证据并给具体核对缺口，不自动补证或放宽16门槛。本包只证明本次已定规则下的新流程。

首证用途检查返回明确的现状证明，不能用缺字段或空列表表示“无需限制”。请求绑定同一玩家、当前CommitId、M05修订、学习目标和原赠物引用；M04核对实际成本后交回证据。

| 当前M05／M04依据 | 对本次学习成本的结论 |
| --- | --- |
| 当前完整一次索引证明尚未领取首证 | 本次没有Level16EntryGift用途限制；M04仍须证明其他证确实可用，不能把未领取当已发证。 |
| 首证已领、教学未完、准确首证仍持有 | 限制这枚证用于战士嘲讽；法师候选仅可从其他合法证产生，不能以T或F总量替代筛选。 |
| 首证已被合法战士学习消费、用途说明未完 | 没有待返还的首证；学习结果和成本凭据保留，说明单独待办，其他证正常可用。 |
| 教学已完成且尚有未消费首证 | 当前完成事实解除该枚证用途限制；T不变，后续实际支出仍须核库存与新修订。 |
| 已领却不能对应赠物／合法消费，或步骤与技能不一致 | 给具体RecoveryBlocked／ReconciliationRequired，不以“找不到首证”批准任意消费或补发。 |

## 7. Challenge、Attempt与通关

| 请求／已有事实 | M05候选与约束 |
| --- | --- |
| 进入未完成关，尚无该关当前Challenge | 创建一个准确PlayerId／LevelId的Challenge；与相关流程变化同提交，重试返回同ID。 |
| 从16退出去旧关1 | 保留16当前Challenge及教学，查询／建立关1自己的Challenge；不能用一个全局“当前挑战”覆盖16。 |
| 失败／主动退出 | 记录必要尝试关系，保留该关Challenge开放；不写首通，不改变其他关挑战，不删除广告资格。 |
| 立即重来 | 原Challenge不变，旧Attempt以Restarted关闭，新Attempt沿原EntryBaseline；与M06／M04联合交接，不另发奖励。 |
| 合法整关胜利 | 准确关闭该Attempt所属Challenge，必要首通／开放事件与M07基础结算联合提交；不能关闭同关之外的挑战。 |
| 已通关关卡重打 | 为本次新挑战创建新ChallengeId，首通键仍已存在；按重打奖励，不能新ID重发一次首通物。 |

同一玩家最多一个活动尝试由M02／M06统一核对；允许多个未完成Challenge不等于允许同时运行多场战斗。预览和教学也不占用M06活动尝试名额。
胜利后旧Challenge和Attempt仍作为原请求／资格／结果的引用依据；M05向M08/M09交准确关闭事实，不操作它们的使用或交付状态。
R03已定未用广告通关机会保留原LevelId，可在同关后续合法尝试手动使用；M05仍执行该尝试正常教学和开放条件，不能凭广告资格跨关或跳过16教学。
未交付在线攻略遇挑战关闭，M05只提供准确关系／关闭原因；资格保留与同关续用、真正交付由SD07／SD09继续。重来新Attempt要重验攻略ContextKey，M05不把旧内容标为当前有效。
