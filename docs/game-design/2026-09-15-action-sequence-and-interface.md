## 出手顺序建议

一次有效连线仍只是一回合。玩家画线期间不播放上方攻击预演；完成合法连线并松手后，按下列顺序完成反馈。上一回合反馈未结束时，不提交下一次攻击，避免视觉快慢影响结果。可以压缩或重叠纯表现，不能改变结算先后。

| 顺序 | 发生什么 | 例子与边界 |
| --- | --- | --- |
| 1 | 确定本次攻击形式与目标 | 飞斧替代原本射程不够的近战；毒箭增强这一发箭，不额外多一段独立道具攻击。没有攻击机会但技能可用时，直接进入技能判断。 |
| 2 | 执行普通攻击及被动追加攻击 | 每发先确认目标及这一发的消耗品，再处理对应的闪避、暴击/格挡与真实伤害，随后处理命中附带状态。已经发射的毒箭即使被躲开也已消耗；这是本轮建议。 |
| 3 | 处理该次攻击的命中状态 | 成功命中的毒箭刷新毒；闪避施毒攻击则不上毒，物理格挡不阻止施毒。直接击杀时不再给尸体挂没有意义的毒。 |
| 4 | 按职业判断自动专属技能 | 先看实际攻击结果，不能只看估算。战士击杀省嘲讽及新 CD，盾骑士仍按原条件给存活队友加盾。技能真正施放才开始 CD。 |
| 5 | 持续伤害，然后存活敌人行动 | 毒等持续伤害在敌人战斗前结算；因此死亡的敌人不再行动。已经完成的敌方行动不能因广告复活再播放一轮结算。 |
| 6 | 本轮结束，处理 CD 与补线 | 本轮新启动的 CD 不立即递减；一个敌方阶段的效果按时到期。存在间接击杀时先免费补线，再开始下一次攻击或胜利结算。 |

步骤 2、3 对每一发顺序执行。双射第一发未杀死目标时，第二发仍按实际库存和开关判断是否为毒箭；第一发已杀死时，第二发普通攻击仍打在死亡残影上产生溢出反馈，不再耗第二支毒箭，不增加有效贡献或重复击杀收益。建议双射只追加一发，不递归触发自己。

这里“先攻击后专属技能”沿用此前已确认的战士/盾骑士判断。法师、弓箭手的具体条件仍属下面的候选，不把所有职业统一成“目标死了就取消技能”。攻击、道具与技能不各占一个回合，也不要求玩家逐项点击。

### 火球的范围与自动施放

已定范围是目标中心及左右各一格，边缘不绕到另一端。建议用本次行动开始时的敌方位置确定三个位置，整次行动完成后再让存活队列前移；下一次攻击的射程照常按存活顺序计算。这样普攻击杀中心后，火球不会突然挪到另一个中心。

建议中心死亡但邻位仍有存活敌人时，法师仍可对原位置释放火球；三个位置都没有有效敌人时不放、不启动 CD。是否对邻位造成等额伤害、火属性倍率、烧伤条件与 CD 交由数值设计提出方案。波及击杀的其他目标依旧免费补线。

## 职业技能候选

**法师默认被动：奥术穿透，方向已在内容任务接受。** 当前具体建议为普通法术攻击有概率忽略目标的一部分法术防御，使用该被动自己的 PRD 积累；触发概率随等级成长。它不增加额外的一次攻击动画，容易保持短局节奏。建议不让火球、毒、烧伤的每一跳都再次触发。触发边界、忽略比例、基础概率与成长幅度待配置；示意的 15% 不是定案。

这样法师对高物防敌人的优势来自法术攻击，对有一定法防的敌人还可能打出穿透亮点。敌人的物防、法防不能按同一数值统一抬高，否则职业差异会被抹平。

**弓箭手专属建议：丛林束缚。** 用户提出精灵弓箭手用植物束缚前排。本轮建议先做单体：本次所连敌人属于当前前排、仍存活且可被束缚时，自动释放，使其不能进行紧接着的敌方阶段攻击，阶段结束失效。射后排时仍可普通攻击，但不自动改选另一个敌人来绑，也不因此消耗技能 CD。主目标已死同样省技能。

束缚与嘲讽分别提供“取消一次敌人攻击”和“改变攻击目标”；盾骑士则吸收伤害。控制免疫必须在敌情中可见，不给所有 Boss 偷加统一免疫。具体哪些敌人能被绑、Boss 是否有缩短控制等例外，等首批敌人表提出选择后再定。

## 成长与战前敌情界面建议

借鉴信息组织与批量操作，不复制《明日方舟》的角色素材、升级公式或整套精英化系统。

1. 角色页首屏保留立绘区域、等级、主要属性和一个升级入口。默认被动显示当前效果，技能显示可用、未达等级或缺职业之证。攻击与生命数值不挤进小头像。
2. 点击“使用经验卡”后在当前画面内打开弹层，压暗背景，不向页面下方追加内容。弹层用上下滚轮选择目标等级：中间数字用柔和圆形光晕突出、上下相邻数字弱化，松手后吸附到整数；同时显示将消耗的卡数、升级前后属性、被动概率、“可升最高”和确认按钮。关闭、点击背景或按返回只取消预览；只有确认时才扣卡并收起弹层，多出的经验留在角色经验条。当前屏幕展示和去掉两条横线是用户要求，圆形光晕及具体布局是本轮视觉建议。
3. 达到 5 级不会自动消耗珍贵的职业之证。技能页显示“等级 5 ✓ / 职业之证 1”，用户主动解锁；首次 16 教学中第一枚通用证用于确认学习战士嘲讽；完成学习与说明后才开战，后续通用证可自由分配。
4. 战前敌情首先展示本关实际敌人及下一步意图，点击一个敌人后显示弱点、抗性和状态免疫，附一句有行动价值的建议。沿用阵容直接开战仍是一键完成，不强制每关阅读资料。

交互示意包含法师升级、批量经验卡、消耗职业之证、三种敌情。示意的铁卫、树灵与毒蛇属性仅用于检验展示方式；不等于首批正式敌人已经配置完成。

## 提示广告、直接通关与全灭建议

免费提示首次点击直接展示完整走线动画。小窗与棋盘按同一顺序播放所有步骤，必要时指示所用角色；上方实际血量、技能和受击状态保持不变。动画最后保留总览、允许重播。玩家首次开始画线后，两处预览一起消失。

免费机会耗尽、此次需要新的攻略时，图标右下角出现广告角标。点击只弹一张确认小窗，说明“观看一次广告，获得完整攻略”，再次点击观看才请求广告，不先列多项菜单。已经获得的同一份攻略重新查看不再收费；角标不能让旧权益失效。广告不可用或没有有效攻略时不消耗权益。偏离攻略后的重新分析计次仍待细化，本轮不重新讨论固化线路冲突。

“广告直接通关”建议放在现有顶部广告菜单中，也放在全灭救援的次要入口。它与看完整攻略用途不同，不能在用户只点免费提示时自动跳关。直接通关给正常解锁、掉落和关卡基础经验；结算增益仍是之后另选，不连播两个广告。

| 回合完整结算后的局面 | 建议处理 |
| --- | --- |
| 小队全倒，敌人仍存活 | 展示单人满血复活、直接通关、重来、退出。此时等待选择，不把等待当成已放弃；复活后如有免费补线，先补完再攻击。 |
| 小队全倒，敌人也已全灭，但尚有线路 | 允许继续免费补线；完成后普通通关，不要求为无战斗收益的补线先看广告。角色仍保持倒下，进入局外恢复。 |
| 小队全倒，敌人已全灭且线路全部完成 | 建议按本关目标已完成结算胜利，同样不免费复活倒下角色。 |

后两项是对“全队倒下即失败”的明确例外建议，需要用户接受。若仍有敌人，则不能利用免费补线继续攻击。等待复活不返还已耗道具；真正退出、重来或结束失败才按原规则返还，避免继续原战斗时重复拥有已经用掉的物品。
