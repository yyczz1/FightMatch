## 参数的使用

`config.json` 保存角色、成长、Boss、技能、广告和时间预算参数。`chapter_model.py` 中的 `LEVELS`、`RECOMMENDED`、`enemy()` 保存普通关出手及逐关敌人规则；`calibrate.py` 生成棋盘试排和材料拆分。它们是策划输入，不预先规定程序架构怎样存储这些数据。

统一 ID：W 战士、M 法师、K 盾骑士、A 弓箭手；敌方 A/B/C 是关内实例，不能与职业 A 混用。正式数据对接时保留类别字段。棋盘坐标从 1 开始、四邻接；每对端点对应一个敌人，默认路线互不相交。死亡空位保留视觉位置；射程按存活敌人序号，不能按地图格距离计算。

数值单位：HP/护盾/伤害为生命点；攻击、防御是属性值；CD/异常持续时间为全队有效回合；概率及伤害系数为比例；库存为整数个数；时间为秒。伤害在所有修正之后向下取整，有效伤害最多记目标扣除的生命。血量中间值保留精度，显示值保留两位，不逐击对剩余血量另行取整。

角色成长：HP＝基础 HP×[1＋0.08×(L−1)]，攻击＝基础攻击×[1＋0.06×(L−1)]，防御＝基础防御＋1.5×(L−1)。本级升级所需经验＝60＋20×(L−1)＋5×(L−1)²。四职业新填的防御/法防、被动概率和后续职业数值都是初版试调值；首章回放不依赖随机被动。

首章评分继续使用内容算例：参考贡献为整关初始敌方生命之和÷2，贡献为有效伤害＋有效嘲讽辅助，倍率＝0.5＋0.5×log₂(1＋贡献/参考贡献)。嘲讽确实把熊王远程从法师转走时，本轮记基攻的一半（26÷2＝13），空放或嘲讽已瞄自己的近战不计。等级修正＝0.75^max(0,自身等级−推荐等级−1)。经验先算基础×评分×等级修正并向下取整，结算广告再乘一次并向下取整。广告直接通关取基础经验，不带本次评分或等级修正；若另看结算广告，才额外乘该结算倍率。

后续保护/恢复的试调口径：真实护盾吸收、真实治疗各记 1 倍生命点；物理格挡避免的伤害记 0.5 倍；正常承受生命伤害记 0.25 倍；束缚阻止一次实际攻击记该次减伤前伤害的 0.5 倍。嘲讽保护事件与相应承伤取两者较高，避免同一受击重复奖励。克制收益已体现在有效伤害中，不另乘一次属性奖励。当前首章历史基线未加入这些新增权重，后续三人职业模型必须启用同一口径后重新校准，不能直接比较两种评分报告。真实贡献不封顶，溢出、尸体受击及空盾不计。
