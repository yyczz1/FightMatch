**最新已定：Boss 满血时上弦不消耗次数；敌我双方死亡后保持原队形、留空不补位；普攻击破中心后火球继续伤害存活邻位，中心与周边伤害分别配置。** 主目标射程仍按既有存活顺序，火球扩散按固定原阵位。中心 100%、每邻位 60% 魔攻仅是起调候选，未作为最终倍率批准。

## 当前配置方向与待验证参数

- **职业解锁立即带来用途：** 法师处理高物防，盾骑士承受前排重锤，弓箭手跨过两名前敌处理恢复来源；不用尚未获得的技能或随机触发强制过关。
- **首章成长按第 8 关入队重算。** 推荐分工、无广告、不用卡时，战士第 12 关达到 Lv.5；第 15 关后 W5＋137、M4＋161，打完 Boss 后法师升到 Lv.5，可衔接第二枚证的火球引导。优先法师输出的分支，战士在第 15 关还缺 8 经验，用已获经验卡中的一张可补足；旧缺 82、用两卡的结果不再沿用。
- **技能解锁立即说明用途并衔接实战：** 嘲讽在第 16 关战前学习，随后直接保护法师；火球群伤与补线、群盾吸收队友伤害、束缚跳过攻击仍随实际解锁教学。引导选角色＋画线自动施放及正确冷却，不把后续职业技能写成人人在固定关号已拥有。
- **Boss 第一面破壳，第二面击破核心。** 远程弹射优先瞄准合法法师，有效嘲讽转向战士；近战重砸遵守前排射程。第一面远程开局，第二面先蓄力、重砸、休整再远程；不靠翻面重置冷却。上弦小工每名两次恢复、每次阶段最大生命 10% 仍为候选。
- **两面一场结算：** 保留血量、道具、CD、状态与 PRD，完整历史撤销可跨面回退；主策划已回传整组接受依据。第一面敌我全倒时先补线、翻面，再救援；最终面敌我全倒仍可免费补线后胜利。当前无消耗品和被动好运算例：正确嘲讽先清兵 11 行动、留兵有效恢复一次 12 行动；无嘲讽 10 行动仅作反事实压力对照，不代表新教学允许跳过学习。全灭／完整状态流程仍需实现验证。
- **每场约 0.8 秒的角色准备：** 战士拔剑、打开脚步、压低重心，法师举杖聚光并转入警戒。前 15 关反复建立熟悉的短节奏；两人并行准备，时长不随人数串行增加。
- **第 16 关约 3 秒的特殊开场：** 熟悉的准备被来影与机械声打断→队员抬头→熊王空中慢姿态→快速落地→队伍受震后重新架武器→名牌与首个意图。3 秒已包含队伍准备。时序为新候选，旧几何演出已被用户否定，不再作为验收样本。
- **普通命中局部顿帧 33～50 毫秒，重击 67～83 毫秒，Boss 落地 83～100 毫秒。** 参数未经过实机测试，画线时棋盘保持稳定。
- **天空、战斗台、下方地形棋盘统一成发条庭院。** 人物按主策划同步的斜九宫格参考做前后纵深错位，下方地形正视操作。第一面草坪翻成地块底部的黄铜检修盘；不随视觉格子改动射程规则。

主题选择属于用户授权本任务决定；整面完成后翻面、穿透方向、第 16 关首次入场／首次通关各一枚证及战前嘲讽教学已有用户回复。其余敌人配置、技能细节、资源边界和数字不会因为写入文档就变成已定配置。

## 接下来优先确定

**正式画风和动作效果：** 推荐清晰轮廓卡通，像素风仍为备选；按主策划回传的用户安排，在可玩初版后集中评审，不作为架构工作的前置门槛。首证与嘲讽教学节点已由最新回复解决。

当前开发顺序为配表与校准 → 架构完成 → 策划、配表、架构联合复核 → 执行初版 → 评审视觉与动作。火球中心／周边倍率、恢复量等由策划继续校准，不要求用户逐个数字批准。本地火球 1.0／0.6 与主配表 0.8／0.4 均为候选，需放在同一固定阵位样例中比较。

角色节点已落实为第一章关卡和成长候选。火球边界详见第一章稿第 7 节；演出改为普通准备与 Boss 特殊开场的同场对照，下一次先验关键姿态、动作连续性和音画击点。新一轮目前完成动作设计，尚未制作新的动画样本。文档区分用户决定、已算样本和仍需实机验证的内容。
