## 1. 建议先采用的试验起点

- 普通关围绕 **3 次有效出手**设计；计算约 14.25 秒。4～5 次出手会上升到 18.20～22.15 秒，不能只压缩攻击动画来解决。
- 首 Boss 先以 **12 次有效出手、约 61.2 秒**检查。已有一个战士 Lv.5、不暴击、不用道具、不用专属技能的单体 Boss 算例；不能在这个预算上直接叠加小怪。
- 等级收益用角色自己的等级计算。推荐衰减底数 **0.75**；初试的 0.80 会让接近前沿的旧关略胜前沿经验效率。
- 新职业建议带适量初始等级入队：法师 Lv.2、盾骑士 Lv.4、弓箭手 Lv.9。经验卡提供自选追赶；技能仍需 Lv.5 与职业之证，等级不替代证书。
- 首版材料先做 **硬铁、灵木、魔尘 3 类**，四职业各一个消耗品配方。普通关基础总材料 2 份、Boss 6 份，主线可不用消耗品完成。
- 结算广告五档已定，概率未定。等概率假设下平均倍率是 2.5；基础单种材料 2 份经向上取整后平均实际拿到 5.2 份，即 **2.6 倍**。要按物品整数计算，不能用平均倍率直接估库存。

下文为这些建议的计算依据。敌人和技能主题见同目录内容候选，教学安排见[关卡节奏草案](2026-09-15-level-cadence.md)。

## 2. 边界与数值表字段

沿用已确认规则：一条有效线产生一次玩家行动及其后的敌方阶段；免费补线不攻击、不消耗、不推进回合。下文时长不是倒计时。所有普通胜利经验按角色分别结算；失败没有收益，退出、重来和失败返还本次尝试消耗。广告直接通关经验按关卡基础经验 `B`，不套评分和等级修正，正常获得该关解锁及掉落；结算增益广告是另一次自主选择。

本轮计算假设在场角色都存活，普通胜利中零贡献角色仍有下文候选保底。倒下队员、未出战队员和广告直接通关中哪些角色领取经验，应由统一结算规则确认，不能从这些算例推导。

### 字段与单位

| 表/字段 | 单位、含义 | 初稿或使用约束 |
| --- | --- | --- |
| `stage` | 关卡编号，整数 | 1～40 |
| `recommended_level` / `R` | 角色等级 | `1 + floor((stage-1)/4)`，不是进入限制 |
| `base_xp` / `B` | 经验点/角色/胜利 | 普通 `18+2×stage`；16/24/32 Boss 为普通公式的 3 倍 |
| `level` / `L` | 每名角色自己的等级 | 不使用队伍平均或最高等级 |
| `next_level_xp` | 经验点 | 从本级升下一级所需，不是累计经验 |
| `max_hp`、`hp`、`shield` | 生命点 | 护盾实际吸收才成为保护贡献 |
| `physical_attack`、`magic_attack` | 伤害点，减免前 | 每个职业只使用自身相应攻击；不默认拥有另一种普攻 |
| `physical_defense`、`magic_defense` | 防御数值 | 本文用除法减伤，100 是尺度常数 |
| `damage_coefficient` | 倍数 | 1.0 是一次本职业普通攻击的减免前伤害 |
| `damage_type` | `physical` / `magical` | 与元素分别记录 |
| `element` | 无 / 火 / 冰 | 金属免烧伤不等于免直接火伤 |
| `element_multiplier` | 倍数 | 中性 1.0；弱点先试 1.25，抗性先试 0.75；实际敌人配置另选 |
| `attack_range` | 存活敌人的顺序数 | 射程 2 是当前前两个活敌；不等于横向两格半径 |
| `aoe_slot_radius` | 横向站位格数 | 火球左右各 1 格；死亡空位如何处理仍需确认 |
| `intent_due_phase` | 第几个敌方阶段 | 时间经过不会提前触发意图 |
| `cooldown` | 之后全队完整回合数 | 开场可用、施放当轮不减，不是该角色出手次数 |
| `status_ticks` | 持续伤害结算次数 | 毒的 3 次仅示意；不能混写成 3 秒 |
| `passive_target_probability` | 长期触发率，0～1 | 交给相应 PRD 标定；不是开场首抽率 |
| `effective_contribution` / `C` | 有效生命点等价值 | 下文输出、保护、恢复、辅助相加 |
| `reference_contribution` / `Cref` | 生命点等价值 | 先用该关敌人初始总生命的 1/2，同一关所有角色一致 |
| `score_ratio` / `c` | 无量纲 | `C/Cref`，没有硬上限 |
| `score_multiplier` / `S` | 倍数 | 下文对数曲线；本身没有硬上限 |
| `personal_level_factor` / `G` | 倍数 | 只影响该角色战斗经验，不缩减背包公共材料 |
| `drop_count` | 个/种类/胜利 | 首通固定奖励与重复掉落分列 |
| `repeat_card_probability` | 概率，0～1 | 仅本轮候选掉落率；与广告档位概率不是一回事 |
| `recipe_inputs`、`recipe_output` | 个/制作批次 | 固定配方，不加入成功率或强化等级 |
| `battle_seconds` | 秒/一场 | 含思考、画线、战斗反馈、免费补线；不含广告和下一关切换 |
| `cycle_seconds` | 秒/取得一次胜利 | 另计换关、失败重试和选择观看的广告 |

所有 `floor` 表示向下取整，`ceil` 表示向上取整。CSV 保留可复核小数；生命表现是否仅显示整数不由这份数学草稿确定。

## 3. 属性与成长

### 四职业的 Lv.1 起点

| 职业 | 生命 | 对应普通攻击 | 物防 | 魔防 | 固有被动的候选长期概率 |
| --- | ---: | ---: | ---: | ---: | --- |
| 战士 | 100 | 物理 20 | 10 | 5 | 暴击 15%，暴击伤害 1.5 倍 |
| 法师 | 72 | 法术 22 | 4 | 14 | 奥术穿透候选 25%，忽略目标 40% 魔防；另有非随机候选，见职业内容表 |
| 盾骑士 | 135 | 物理 13 | 24 | 8 | 物理格挡 20%，本次物理直接伤害减少 50% |
| 弓箭手 | 85 | 物理 16 | 6 | 8 | 双射 15%，追加 1 发 1.0 倍普通箭 |

初稿成长采用线性增量，方便看出等级差的效果：

```text
生命(L) = Lv.1生命 × [1 + 0.08 × (L-1)]
攻击(L) = Lv.1攻击 × [1 + 0.06 × (L-1)]
物防(L) = Lv.1物防 + 1.5 × (L-1)
魔防(L) = Lv.1魔防 + 1.5 × (L-1)
```

这里每级增加的是初始值的 8% / 6%，不是逐级复利。例如战士 Lv.5 为 132 生命、24.8 攻击、16 物防、11 魔防；Lv.10 为 172 生命、30.8 攻击、23.5 物防、18.5 魔防。

被动成长先只做 Lv.1～15 的配置区间，统一使用职业表的两个锚点：战士 Lv.1 为 15%、Lv.10 为 22%；盾骑士 20%→28%；弓箭手 15%→23%；法师若选奥术穿透为 25%→32%。各级先按 `p(L)=p(1)+[p(10)-p(1)]×(L-1)/9` 插值，例如战士 Lv.5 长期目标约 18.1%。更高等级另配，不能把此线性公式无限外推至超过 100%。不因此给其他职业增加暴击、给所有角色添加基础闪避或普通命中率。

### 伤害口径

```text
直接伤害 = floor(对应攻击 × 本次系数 × 100 / (100+对应防御) × 元素倍率 × 本次其他倍率)
有效伤害 = min(直接伤害, 受击前剩余生命)
```

这是调试起点。该区间不加入防御破负等额外规则。法师穿透例：魔防 50 时，普通减伤系数是 100/150；穿透后按 30 魔防计算，为 100/130。穿透仅提高该次法术伤害，零魔防目标不会因此得到固定额外伤害。其具体 PRD 类型仍是职业候选，不能混用战士暴击的积累。

毒候选每次结算 `floor(弓箭手攻击 × 0.15)`，先试 3 次；直接箭仍按物理防御减伤。毒的防御结算方式是本模型新增候选，后续需与状态表一起确认，不能因“不闪避、不格挡”就断言所有其他减伤都无效。本文的时长、首 Boss 和前 40 关成长均不靠毒达成。

PRD 长期概率不能直接当作每场 3 次攻击的稳定加伤。以下首 Boss 检查完全不触发被动；道具预算中双射的 15% 只作长期消耗量敏感性假设，须另查短战斗中重置 PRD 的实际触发分布。

## 4. 升级、评分与新职业追赶

### 升级需求

```text
从 L 升到 L+1 的经验 = 60 + 20×(L-1) + 5×(L-1)²
```

| 等级 L | 升下一级所需 | 从 Lv.1 到当前等级累计需要 |
| --- | ---: | ---: |
| 1 | 60 | 0 |
| 2 | 85 | 60 |
| 3 | 120 | 145 |
| 4 | 165 | 265 |
| 5 | 220 | 430 |
| 6 | 285 | 650 |
| 7 | 360 | 935 |
| 8 | 445 | 1,295 |
| 9 | 540 | 1,740 |
| 10 | 645 | 2,280 |

### 每名角色的贡献

候选 `C = D + P + H + A`，各项不硬封顶：

- `D`：实际削掉的敌人生命，包含归属该角色的有效 AOE、毒伤。尸体、双射第二发溢出、过量伤害不计。
- `P`：护盾实际吸收量、物理格挡实际减掉的伤害。天然物防减免先不另外加保护分；未吸收的盾不计。
- `H`：实际补回的缺失生命。满血过量治疗不计，广告复活不伪造为某角色治疗。本轮不新增治疗技能。
- `A`：控制或嘲讽实际影响一次到期敌方意图时，先试计 `0.5×本关敌人基准攻击 E`。嘲讽需真实改变原目标，束缚需真正阻止当阶段原本会发生的攻击。对蓄力中的敌人反复上状态、刷新但没有影响意图，不重复记分。

同一伤害减少量在 `P` 中只记一次；束缚已取消的伤害不能再记一遍护盾吸收。辅助按影响事件给分，不把转移伤害全额虚构成净减伤。这是便于首测的评分候选，不是要求架构添加完整反事实战斗模拟。

基准 `Cref = 本关敌人初始总生命 / 2`。Boss 血多因此参考贡献也提高；同一关所有角色使用相同参考值，不能单凭“有护盾技能”发固定高评分。

### 评分曲线与等级修正

```text
c = C / Cref
S(c) = 0.5 + 0.5 × log2(1+c)
G(L,R) = 0.75 ^ max(0, L-R-1)
正常胜利经验 E0 = floor(B × G × S)
选择结算广告后的总经验 E = floor(E0 × 广告档位)
广告直接通关经验 E0 = B
```

先计算并展示正常整数经验，再对这份奖励应用广告档位，便于玩家核对。经验整数取整仍为数值候选；已确认的材料向上取整另算。结算广告不是额外再加一份原奖励，例如 E0=100、档位 2.5，最终总计 250。

| 贡献比例 c | 评分倍率 S | 含义 |
| ---: | ---: | --- |
| 0 | 0.500 | 无贡献在场角色的候选保底 |
| 0.25 | 0.661 | 少量有效辅助或伤害 |
| 0.5 | 0.792 | 约半份参考贡献 |
| 0.8 | 0.924 | 三人示例常用假设 |
| 1 | 1.000 | 一份参考贡献 |
| 2 | 1.292 | 单人清空全关血量时的纯伤害贡献 |
| 4 | 1.661 | 更高真实贡献仍增长 |
| 10 | 2.230 | 增长已经明显放缓 |
| 100 | 3.829 | 继续增长，没有硬顶 |

等级不超过推荐值 1 级时 `G=1`；超过推荐值 2、3、4、5 级时分别为 0.75、0.5625、0.421875、0.316406。低级新人不因高等级队友同行而被统一衰减，也暂不额外增加低等级经验倍率，追赶优先通过初始等级和经验卡解决。

这是独立经验，不是固定经验池：设同一关 B=90、Cref=100，战士贡献 100、盾骑士贡献 100，等级修正都为 1，则各得 90。一个人的分数提高，不直接扣另一个人的经验。三人评分都接近 1 时，发出的角色经验总量会高于单人，这是本规则的自然结果，需要按角色成长分别验收。

对数递减也不能单凭公式保证没有拖延刷分问题。示意在 B=90、G=1 下，c=1、4、10 分别耗战斗 15、45、90 秒，另加 2 秒换关，可得约 318、190、130 战斗经验/分钟。长期反复产生真实贡献仍增加单场奖励，但这里时间增长快于奖励增长。思考时间本身不扣分。

### 新职业：推荐与替代

| 方案 | 具体入队方式 | 取舍 |
| --- | --- | --- |
| **推荐：带起始等级入队** | `max(1,R-1)`，10 关后法师 Lv.2、20 关后盾骑士 Lv.4、40 关后弓箭手 Lv.9 | 不用额外礼包把刚解锁角色从 1 级拉到前沿；技能证书门槛保持独立 |

推荐只有一种通用经验卡，**每张 50 经验，可用于未上场角色**。不受使用目标等级衰减，保留超出当前升级所需的经验到下一级。这里不设计新的卡牌稀有度或职业限定卡。

无广告演算：4、8 关首通得到的 2 张卡给法师，可从 Lv.2 升到 Lv.3，多 15 经验；20 关结算后再花 4 张给盾骑士，从 Lv.4 升到 Lv.5，多 35 经验。没有自动强制使用卡。

### 1～40 关成长演算

假设每关首次尝试均胜利、无结算广告、不计随机复刷卡；前 10 关战士独自贡献 `c=2`，11～20 关战士和法师各 `c=1`，21～40 关三人各 `c=0.8`，后者容许实际保护/辅助贡献。新职业在解锁该关结算后入队，不倒领奖励。用上段 2 张、4 张卡的追赶方式。

| 节点 | 战士 | 法师 | 盾骑士 | 弓箭手 | 关键检查 |
| --- | --- | --- | --- | --- | --- |
| 10 关后 | Lv.4 | 新 Lv.2，给 2 张卡后 Lv.3 | 未解锁 | 未解锁 | 不把法师当作 10 关首战可用队员 |
| 12 关后 | **Lv.5** | Lv.3 | 未解锁 | 未解锁 | 战士已满足等级，但还没有证，不能嘲讽 |
| 16 关战前 | **Lv.5** | Lv.4 | 未解锁 | 未解锁 | **两人都没有专属技能** |
| 16 关后 | Lv.6 | Lv.5 | 未解锁 | 未解锁 | 首次仅 1 枚证，只能先给一人解锁 |
| 20 关后 | Lv.7 | Lv.6 | 新 Lv.4，给 4 张卡后 Lv.5 | 未解锁 | 盾技能仍需有证可用 |
| 40 关后 | Lv.10 | Lv.10 | Lv.9 | 新 Lv.9 | 弓箭手不能被用来证明 1～40 首战必过 |

全程只用 6 张首通卡，40 关后留有 7 张。若把这 7 张全给刚入队弓箭手，则 Lv.9 获得 350/540 经验，仍在 Lv.9；不需要为了职业技能的 Lv.5 门槛继续补卡。

广告敏感性另算了一个明确情景：**每一关都选择结算广告，并且每次恰好落在 2.5 档**；经验卡暂用向上取整候选，仍只花上述 6 张追赶卡，不额外使用广告多出的卡。这不是“随机期望等级”，因为升级和衰减是非线性的。此情景 40 关后三名老角色均 Lv.12，弓箭手仍以 Lv.9 入队，库存余 30 张卡。若全部投入新弓箭手，1,500 经验可把它升到 Lv.11，余 315 经验；因此不能只校验完全不看广告的一条主线。

逐关数据见 [balance-progression.csv](balance-progression.csv)，共 80 行，包含无广告和固定 2.5 档两种假设。未包含死亡、额外刷关或玩家对贡献的实际选择。

## 5. 15 秒与 60 秒的计算

### 拆开计时

```text
战斗时长 = 进场及结算固定时间
         + 有效出手数 × (思考 + 画线 + 玩家反馈 + 该次敌方阶段总反馈)
         + 免费补线数 × 每次补线时间
一次胜利周期 = 战斗时长 + 换关 + 失败重试时间 + 主动选择的广告时间
```

普通关每次先试思考 1.3 秒、画线 1.3 秒、玩家反馈 0.65 秒、整个敌方阶段反馈 0.70 秒，加固定 2.4 秒；Boss 每次分别 2.0、1.3、0.7、0.9 秒。敌方阶段的 0.70 秒是**本阶段所有敌人反馈的总预算**，不是每个敌人都可占 0.70 秒；这些顺序和重叠方式由主策划确认后需要重测。没有真实动作的敌方阶段也不应被机械加入空等待。下表按每次阶段留预算，最终击杀后若该阶段没有反馈，应扣除相应预算；例如首 Boss 的 61.2 秒可因此少 0.9 秒。

| 假设场景 | 有效出手 | 免费补线 | 战斗时长 | 含 2 秒换关的周期 |
| --- | ---: | ---: | ---: | ---: |
| 普通关 | 3 | 0 | 14.25 秒 | 16.25 秒 |
| 普通关增加一次出手 | 4 | 0 | 18.20 秒 | 20.20 秒 |
| 普通关需要五次出手 | 5 | 0 | 22.15 秒 | 24.15 秒 |
| 新玩家，每次思考 3 秒、画线 1.8 秒 | 3 | 0 | 20.85 秒 | 22.85 秒 |
| AOE 改为两次出手，但有两条免费补线 | 2 | 2 | 14.70 秒 | 16.70 秒 |
| Boss 标准 | 12 | 0 | 61.20 秒 | 63.20 秒 |
| Boss 毒/AOE 少两次攻击，增加两条补线 | 10 | 2 | 55.80 秒 | 57.80 秒 |

免费补线每次先试 2.2 秒，含辨认与画线；“免费”是回合和消耗免费，玩家仍要花时间。满棋盘或难路线会进一步增加思考。完整历史撤销和重试耗时需在试玩另记，不能藏进攻击动画预算。

若每 5 次尝试中有 1 次失败，即每次成功平均对应 0.25 次失败，失败尝试连同重开平均 12 秒，则普通关取得一次胜利需额外 3 秒，周期变 19.25 秒。这个比例只是批量测算假设，实际玩家会学习，不能把重复同一操作视为每次都会独立重新抽到成功。

## 7. 五档广告与整数的实际效果

### 两组概率只供敏感性检查

| 假设 | 2.0 | 2.2 | 2.5 | 2.8 | 3.0 | 平均倍率 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 均匀假设 | 20% | 20% | 20% | 20% | 20% | **2.50** |
| 低档偏重假设 | 35% | 25% | 20% | 15% | 5% | **2.32** |

两组都不是用户确认概率。轮盘随机停止已定，不能把玩家点击时机当作技巧提高概率，也不能从这份表直接发布掉落承诺。

### 材料向上取整

建议同一种材料在一场的奖励先合并，再向上取整；合并粒度尚待统一结算确认。如果把同种材料拆成很多个 1 份小条目后各自取整，会增加与内容无关的产量。

| 某种材料基础数量 | 2.0 后 | 2.2 后 | 2.5 后 | 2.8 后 | 3.0 后 | 均匀假设平均数量 | 实际平均倍数 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 2 | 3 | 3 | 3 | 3 | 2.8 | 2.800 |
| 2 | 4 | 5 | 5 | 6 | 6 | 5.2 | 2.600 |
| 3 | 6 | 7 | 8 | 9 | 9 | 7.8 | 2.600 |
| 6 | 12 | 14 | 15 | 17 | 18 | 15.2 | 2.533 |
| 10 | 20 | 22 | 25 | 28 | 30 | 25.0 | 2.500 |

Boss 6 份若分为三种各 2，则均匀假设平均总数为 `3×5.2=15.6`；单种 6 份则为 15.2。两者差异来自逐种整数取整，不是浮点错误。0 份乘任何倍率仍为 0，不产生原本未掉落的物品。

若领取结算广告的胜利占比为 a，经验在忽略少量整数损失时平均产出因子为 `1+a×(2.5-1)`；每关单种 2 份材料的因子为 `1+a×(2.6-1)`：

| 广告领取占比 | 战斗经验近似因子 | 2 份主材的实际期望因子 |
| ---: | ---: | ---: |
| 0% | 1.000 | 1.000 |
| 25% | 1.375 | 1.400 |
| 50% | 1.750 | 1.800 |
| 100% | 2.500 | 2.600 |

因此 20 次普通胜利无广告基础 40 份材料，在 50% 广告领取、均匀档位假设下期望 72 份，全部领取则期望 104 份。实际关卡选择决定各类数量，不能按这个总数假定魔尘一定够。

### 经验卡整数：保留两案供选择

| 候选 | 基础 1 张的五档结果 | 均匀假设平均 | 优点与成本 |
| --- | --- | ---: | --- |
| **推荐：向上取整** | 2 / 3 / 3 / 3 / 3 | 2.8 张 | 与材料一致、结果直观；小数量礼包实际比 2.5 倍多，需要计入投放 |
| 向下取整 | 2 / 2 / 2 / 2 / 3 | 2.2 张 | 更保守，但多数档位在 1 张奖励上看不出区别，需明确展示整数结果 |

基础 2 张时，向上平均 5.2、向下平均 4.8。首 40 关保证卡包含 7 次 1 张与 3 次 2 张，基础共 13 张；每次都领广告且档位均匀时，向上期望 `7×2.8+3×5.2=35.2` 张，向下期望 `7×2.2+3×4.8=29.8` 张；不能直接写成 `13×2.5=32.5` 张。这里都只是期望，不发小数卡。

不推荐首版另加碎片进度、暗存小数或第二次随机补 1 张，避免为了消除少量取整差异增加新的解释成本。本节推荐仍须用户选择，不能沿用材料已定向上取整就自行批准卡的取整规则。

### 广告时长与经验/分钟

用视频 30 秒、轮盘/返回反馈 2 秒，共 **32 秒额外时间**检查；另算视频 15/45 秒，对应额外 17/47 秒。真实视频时长和关闭交互尚未测量。

| 情景 | 无结算广告，合计经验/分钟 | 每胜利领结算广告，合计经验/分钟 | 解释 |
| --- | ---: | ---: | --- |
| Lv.10 刷 8 关 | 53.57 | 28.81 | 极短局中广告时长超过节省的重复战斗时间 |
| Lv.10 刷 36 关 | 324.92 | 275.07 | 单次奖励更多，但此假设下单位总时间略低 |
| Lv.10 刷 32 Boss | 173.26 | 289.92 | 较长战斗中广告明显提高单位总时间收益 |

表中卡使用向上取整候选，并把全部卡经验给所列角色。概率、时长或卡处理改变后要重算。只看普通经验，忽略整数时，2.5 倍广告的时间收支平衡点为额外广告时间 `1.5×原胜利周期`；普通 16.25 秒周期对应约 24.38 秒。广告可省手动重复操作，但不必对每种局长都保证最高经验/分钟。

广告直接通关另算：36 关直接发 B=90，无评分/等级修正；假设从进入到该项广告及结算、换关共 36.4 秒，战斗经验约 148.35/分钟，公共期望卡经验另约 8.24/分钟。若玩家随后再自主选择结算广告，合计两次广告，周期 68.4 秒，均匀假设战斗经验为每次 225、约 197.37/分钟，公共卡另约 12.28/分钟。两项不能自动连播。

CSV 留有“4 关广告直通若错误套等级修正”的非采用对照：B=26 会被削成 2。正式主口径保持 26，用于提醒审核不能把正常战斗经验公式整体复用于广告直通。

档位及取整完整结果见 [balance-ad-economy.csv](balance-ad-economy.csv)，49 行，含 0、1、2、3、6、10、99 的数量检查。角色解锁和首通职业之证在所有倍率下都不增加数量。

## 8. 验证记录与下一次应测什么

2026-09-15 用临时计算脚本实际生成并重读 4 张 CSV：成长 80 行、时间 14 行、刷关 15 行、广告整数 49 行。计算命令退出码 0；检查了两组概率合计为 1、均匀档位期望 2.5、材料向上取整不小于精确乘积、CSV 行数/字段完整、首 12 关后战士 Lv.5、首 16 关前无证、16 首通仅第一枚证、40 解锁前弓箭手未参与、无广告用卡后余 7 张，以及首 Boss 12 次攻击后战士剩 13 生命。

这次没有 Unity 编译、实际战斗模拟器、棋盘求解或设备计时结果。表中只证明算式和给定场景的数值，不证明完整攻略存在或经济已经平衡。

下一轮先测三件事即可：

1. **普通 3 次出手与 Boss 12 次出手的真实计时。** 在手机上分别记录新玩家和熟悉玩家的思考、画线、敌方反馈、免费补线与撤销时间；同步判断单体 Boss 是否过多重复。
2. **无广告、无必需消耗品的 1～16。** 验证战士达到 Lv.5 的实际贡献路径，并分别用单战士、战士＋法师完成首 Boss；记录受击、路线堵路及失败原因。不得用嘲讽或火球填补缺口。
3. **同一批关卡的资源压力。** 对照不看广告、半数领取、每次领取；再对照毒箭全开/按需关闭和法师火硝全开，观察公共材料瓶颈、卡库存和职业成长。第 40 关新弓箭手之后的技能/双射 PRD 测试另开小样，不倒灌为前 40 关通关条件。

需要用户本轮选择的数值方向优先是新职业入队等级方案、经验卡取整，以及是否采用 3 材料/四固定配方作为首测集合。普通/Boss 时长、掉落概率和最终属性应等这些小样结果再收敛。
