## 2. 具体映射为何与已定规则一致

**R01 区分“用掉”与“回收”。** [原主策划广告条款](D:/Unity/UnityProj/FightMatch/docs/game-design/2026-09-14-fightmatch-game-design.md:215)已明确，撤回那次复活使用就恢复对应机会，未撤回而再次死亡则不能重复免费复活。立即重来丢弃旧尝试历史，所以恢复其中被撤回使用的机会；直接退出按最终状态结束，保留已发生的使用及未用机会。两者都不删除广告事实，不把所有广告变成不限次服务。

**R02 仍按原本局重试。** [架构接收记录第 3 节](D:/Unity/UnityProj/FightMatch/docs/system-design/2026-09-16/planning-review-receipt.md:25)与原内容解释一致。战斗快照不能覆盖最新永久成长或现实时间；原来未参战的恢复中角色也不能被重来自动加入。内容侧签收已完成，不能代替主策划签收。

**R03 保留用途，取消旧挑战的失效条件。** 原广告为某关通关而取得；限定原 LevelId 可保留用途，手动使用避免迟到回执自动结束当前游戏，一次性沿用原广告效果。ChallengeId／发起 AttemptId 继续作来源，不再决定未用资格是否过期。资格不转换为别关、复活、货币或结算倍率。

兑现仍须核对资格属于当前玩家、尚未有效使用、目标关卡相符及当前尝试合法，包含既有教学和可出战条件；只比较 LevelId 相同不足以发奖。资格保留不会自动跳过第 16 关的嘲讽教学。

**保留资格与重复发奖不同。** 后续合法 B 使用机会，只按 B 的入场参战者、绑定配置、真实消耗及广告基础经验结算；原 A 的正常奖励不回收、不改成广告经验，也不重复发。B 若为已通关关卡的新挑战，正常重打奖励仍按已有规则产生，首通证和职业解锁不再发。允许用在新的 B 会使参战者、等级和消耗与广告发起时不同；兑现前应显示实际目标和奖励／消耗依据，这一影响继续明确保留。

两份不同且已核验的广告权益不能因来源同关或同挑战而合并成一份。一次结算实际用掉 g1，另一份未用 g2 继续保留；同一请求／事实的重复回调则只有一份机会。不因此新增自动播放广告或主动囤积广告的入口。

## 3. 原 35 个场景的现行预期

编号按上一轮各表行序对应。以下是**更新后的设计预期**，不是游戏或 SDK 测试通过记录。R01 的 8 项处理采用已核对解释，R02 的 10 项保持原基线，R03 的 17 项按不回收原则重写；不能沿用“旧 35 项原样通过”的说法。

### R01：8 项

| 编号 | 场景 | 当前预期 |
| --- | --- | --- |
| R01-01 | g1 经 u1 复活后再次倒下，直接重来 | 撤回旧尝试有效 u1，g1 恢复一次。新尝试按原入场 HP 初始化，不额外消耗或增加 g1 |
| R01-02 | 先撤销到 u1 前，再重来 | 撤销已恢复 g1，重来只保留；与直接重来结果相同，不能再加一次 |
| R01-03 | 广告完成，g1 未用便重来 | g1 保留一份可用机会，不重播广告、不自动使用 |
| R01-04 | u1 未撤回，再次倒下并继续本尝试 | g1 仍已用；无其他适用未用机会时需新广告。再次死亡不等于撤销 u1 |
| R01-05 | 使用后直接退出 | u1 保持已用，按最终存亡交接局外恢复；其他未用或已撤回使用的机会保留。先撤销再退出仍保留撤销结果 |

| R01-07 | 新尝试再用 g1 形成 u2，然后重来 | 只撤回当前尝试有效 u2；不批量恢复早前结束尝试或局外恢复中仍有效的使用 |
| R01-08 | 重复回调／重来提交，或旧 u1 撤回晚到 | 同请求／事实只一份资格、同操作只一次结果；旧 u1 不能释放已有效的 u2。查询原结果，不按重试次数增发 |

## 4. 其他广告用途与尚待细化处

| 用途／场景 | 本轮确认的边界 |
| --- | --- |
| 已获结算增益，离页或换关后才兑现 | 资格保留，作用原 SettlementId 的固定基础奖励，只发应追加差额；不转当前页面、不重复基础收益 |
| 已获资源资格，跨天后兑现 | 原报价及原期间归属保留；不重新报价、不占新期间第二次名额，不因跨天清掉已得资格 |
| 广告经验／卡已发放，之后撤销战斗或正常用卡 | 已发永久收益不因战斗回退减少；玩家正常使用卡是消费，不能据“不回收”自动补回 |
| 在线攻略已取得权益但服务失败，随后旧挑战通关 | 未交付资格继续保留、可重试，不能标已交付或随挑战删除；同关续用需记录实际新目标与交付结果 |
| 已交付攻略，本挑战继续／结束 | 本挑战内仍按既有持续解析范围服务；已交付内容持续可看。挑战结束后的已交付服务不自动扩成无限跨关分析 |

在线攻略的具体剩余场景是：**广告权益已取得，但有效攻略尚未交付，玩家先自行通关；下一次同关重打如何继续取得服务。** 共同契约 H07／H09 已要求保留并细化同关续用，内容侧认可该方向。SD07／SD09 后续对话需明确入口、实际请求归属、当前局面验证和可读取的交付结果；请求发出、SDK 完成或收到不可用文本都不能直接等同攻略已交付。若此前已有可用内容但本次更新失败，还需区分已交付部分与仍欠交付的请求，不能重置为无限服务，也不能一句“以前交过一次”便清掉未交付部分。

默认免费攻略不能消费在线资格；过时结果可以带原适用条件保存回看，但不自动算作已经交付当前局面的服务。具体续用对象和服务期仍须明确，不能把 R03 的“新 ChallengeId 可用一次通关权”直接复制为“每个新挑战自动重开完整在线服务期”。

这属于下一次具体场景的职责与完成条件核对，不重问广告权益是否保留。本轮不自行确定跨关服务、补偿货币、额外次数、过期时间或新广告入口。若未来方案必须减少已得权益，需先列出与用户新原则的实质冲突；目前核对未发现必须改变该原则的情况。
