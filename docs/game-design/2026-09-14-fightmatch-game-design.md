## 01 · 游戏要给玩家什么感觉

玩家在手机下方选一名队员，连接一对同色端点。连线完成，角色立刻出手：端点与线路同步重击，敌人受创；击杀后线路留下，成为后续走线必须绕开的地形。上方保留横向对阵，人物采用斜九宫格的纵深站位，前排靠近敌人，后排退后错开。九宫格先作为视觉参考，仍按既定三人顺序计算射程；不因画面出现九格就增加九人阵容或自由布阵规则。敌人的下一步行动清楚可见，玩家再决定先处理哪一个目标、让谁来承担危险。

小队的价值来自差异：法师处理物防高的敌人，远程职业越过近处目标，战士通过嘲讽改变敌方攻击目标，盾骑士为队友提供护盾。玩家可以因为正确的职业和顺序干净利落地过关，也可以因为走线堵路或战术失误失败。

| 项目 | 当前方向 |
| --- | --- |
| 设备 | 手机，优先 Android；本案以竖屏展示，正式屏幕布局仍可调整 |
| 单局节奏 | 普通关约 15 秒，Boss 关约 60 秒，均为待实测的目标 |
| 操作重心 | 棋盘与下方队员头像；减少上下跨区域切换 |
| 战略层 | 战前阵容与顺序、局外等级和装备 |
| 战术层 | 选谁出手、先打谁、怎么走线、何时保护队友 |
| 时间压力 | 思考和画线不推动敌方回合；不靠倒计时催玩家操作 |
| 盈利方向 | IAA，以玩家主动选择的激励广告为主 |

参考成品为 [Monster Match](https://poki.com/zh/g/monster-match)。本案沿用用户希望保留的同色连线、战斗反馈与击杀占格体验，并扩展为 RPG。参考游戏的细节不自动成为本项目规则。

## 02 · 从准备到下一关

**选关（按需调整阵容）→ 选择角色并连线 → 玩家出手 → 敌方阶段 → 继续连线 → 胜利结算 → 养成或下一关。**

局外采用选关地图作为主界面，底部导航为冒险、队伍、背包。地图展示当前关卡并支持重打旧关。普通连续关沿用当前阵容直接开战，需要时再进入准备调整，不强制每关返回地图或确认准备。

战前允许更换最多三名队员并调整顺序，展示敌人配置、关卡推荐等级和主要掉落。推荐等级帮助判断难度，不作为禁止进入的门槛。

**每个职业仅对应一名可培养角色，不拥有多个战士或多个法师。** 开局按战士一人安排，后续按关卡逐步获得其他职业。当前采用法师第 8 关、盾骑士第 21 关、弓箭手第 37 关通关后入队。允许仅一名或两名存活成员出战；正在恢复的已选队员保留其位置与恢复状态，不因此自动换人。

队伍页上方展示当前三个位置与站位，下方展示已拥有角色。点击头像进入成长详情，通过换人入口从下方角色中选择替换，拖动排序把手调整顺序，战术槽进入装配。战前准备沿用这套队伍布局，并增加本关敌人、意图、推荐等级和掉落信息。

少人出战直接通过上方阵容表达：存活头像正常、倒下头像显示恢复状态、空位保持空槽；不额外重复显示“本次 2 人出战”的提示。三名已选队员全部不可出战时需要先调整阵容或恢复成员，才能开始新战斗。

战斗中，玩家可以反复选择同一角色，不强制轮流出手。每次有效完成连线只提交一次行动，不再加入行动点，也不增加独立的主动技能操作按钮或技能目标选择。玩家通过选角色和连线决定出手，攻击与职业技能按各自条件自动执行；是否在击杀后跳过技能，由该职业技能的规则决定。

击败本关所有敌人并完成待补线路后胜利。毒或 AOE 间接击杀缺少本次线路时，需要先免费补线再结算。无需铺满整个棋盘，也不要求只能有唯一解。队员全部倒下则进入失败状态，仍提供复活、重来和退出等适用选择。只剩盾骑士时，玩家随时可以结束这次尝试，不必一直磨血。

## 03 · 连线与占格

每关由固定棋盘与固定敌人组构成。每名敌人对应一对同色端点；首版不在当前棋盘中途增援新敌人。

1. 选择下方存活队员后，所有端点的中心符号切换为该职业。端点颜色继续对应敌人。
2. 从一端出发，沿横竖相邻格画线。线路不能交叉、重叠或穿过其他端点。
3. 手指尚未松开时可以沿原路回退修正。没有在配对端点完成的线路不提交行动。
4. 在另一端完成并松手，结算这名角色对该敌人的攻击、技能及后续敌方阶段。
5. 没有击杀本次连线目标时线路在反馈后消失；直接击杀该目标时本次线路固化，继续占格。

**毒和 AOE 可以直接杀死敌人。** 因持续毒伤或 AOE 波及而死亡、没有本次线路可固化的敌人，死亡后提示玩家连接其端点；这次补线不计入攻击回合，不造成再次攻击，不推进技能 CD 或敌方行动，也不重复消耗道具或发放击杀收益。连接完成后才固化对应路线，仍遵守原有合法走线路径与占格约束。

待补线的敌人已经死亡，不继续攻击；其端点保留颜色，用“待连线”状态区别于存活敌人和已固化端点。不能自动套用最初施毒路线或默认解。当前正常回合结算完后，必须先补完这批死亡敌人的线路，再允许下一次攻击。多条待补线可自行选择顺序；即使敌人全部死亡，也要补完再结算胜利。线路堵死仍可能失败，可撤销或重来。

用户要求补线使用图形，不在端点写“待”等汉字。当前表现改为原色空心圆与呼吸外环，完成后变成同色固化形态及完成图标；多条同时提示而不指定顺序。棋盘上方可以保留必要的简短说明，端点本身靠图形区分。全部补完后恢复攻击或进入胜利，具体提示强度与文字停留时间仍可调整。

示意可切换毒击杀与 AOE 清场，拖动端点试画，或播放完整动效。自动走线仅用于演示播放，正式玩法由玩家手动补线；示意中的 CD、关卡数字与动效参数不是正式数值。

固化路线可以不同于关卡参考解。一条线路当下合法，不代表余下局面一定能完成。玩家因此堵住其他颜色的去路属于可接受的失败来源，可以撤销、重来或使用帮助。

## 04 · 一次攻击应该看起来怎样

**端点也要一起打出去。** 攻击时只让线路变粗会显得端点与线脱节，因此起点、终点和线路共用一个清晰的重击节拍。

| 阶段 | 棋盘表现 | 玩家应理解的结果 |
| --- | --- | --- |
| 连接完成 | 同色线路迅速补齐，角色与目标短暂呼应 | 这次行动已提交 |
| 重击 | 两端核心轻压缩、弹大再回稳；线路同步加粗、闪亮 | 攻击命中并产生力量感 |
| 未击杀 | 线路缩细、收束并消失，端点恢复待选 | 目标仍存活，可以再次攻击 |
| 击杀 | 重击后线路形成更稳定的实体质感并保留 | 敌人已死，这些格子继续占用 |
| 仅技能可达 | 外环发出技能波，线路流动后消失，不播放物理重击 | 本次只有技能效果，没有攻击伤害 |

示意可切换“攻击＋技能 / 仅攻击 / 仅技能 / 都不可达”，并分别播放未击杀与击杀。它用于观察射程和反馈，不模拟职业自动施放判断或 CD。动画故意留出观察时间；正式关卡要压缩重复反馈，避免少量连线也拖成长战斗。

端点距离提示采用已认可的双层轮廓：**实线内框表示攻击可达，虚线外环表示技能可达。** 同时使用颜色、形状与文字说明，避免只依赖颜色。后续正式角色可以使用剑、杖、弓、盾等职业符号；阅读版保留可直接识别的文字与符号，防止图标未加载时出现空白。

玩家画线期间不预演上方攻击；合法连线完成并松手后，才播放实际战斗。攻击、消耗品与专属技能的详细先后见[已接受的三组规则](2026-09-15-three-group-recommendations.md)：攻击形式（含道具）→ 每发伤害与命中状态 → 被动追加攻击 → 按职业判断专属技能 → 敌方行动前全场持续伤害统一结算一次 → 存活敌人行动 → 本轮结束及免费补线。道具不额外占一回合；完整顺序及职业技能边界已接受，具体效果量与倍率仍属试调参数。

## 05 · 独立血量、射程与敌方意图

三名队员各自拥有生命、攻击、防御与职业能力。战斗界面分别显示血量，不显示小队总血量。盾骑士和输出角色的生存、输出能力存在取舍。

射程按目标队列中**仍存活的单位顺序**计算。例如敌人为 A、B、C，射程 1 能打 A，射程 2 能打 A 与 B；A 死亡后，射程 1 能打 B，射程 2 能打 B 与 C。固化线路仍保留，不影响敌方存活顺序前移。

| 攻击距离 | 技能距离 | 连线结果 |
| --- | --- | --- |
| 可达 | 可达 | 执行攻击；技能满足可用条件及该职业的自动施放规则时执行 |
| 可达 | 不可达 | 只攻击 |
| 不可达 | 可达 | 技能满足施放条件时，只施放技能，消耗本次行动 |
| 不可达 | 不可达 | 端点置灰，不能提交这条连线；端点仍占格 |

射程可达不等于技能必定施放：还需检查解锁、CD、合法目标及职业规则。原有仅技能行动保留，不因普攻距离不足而一并取消可用技能。

敌人区分近战、远程与特殊类型。近战按射程处理前面的合法目标；远程可威胁后排。敌人显示下一次行动及其触发时机，玩家完成一次行动后推进敌方阶段，达到行动时机的敌人执行相应行为。各敌人的行动频率、目标优先级和数值随关卡配置确定，尚未制定最终表格。

毒蛇等特殊敌人可以用中毒制造不同威胁。毒采用三次结算、同类刷新不叠层；护盾吸收毒伤但不阻止施毒。具体每跳伤害与敌人首次出现关号由内容表校准。

## 06 · 职业与保护队友

队伍上限三人，职业池可以超过三种，每职业仅一名角色。玩家进入战斗前的取舍本身就是策略。

| 职业 | 已确定的定位与能力方向 | 尚需确定的内容 |
| --- | --- | --- |
| 战士 | 近距离物理攻击；默认被动有概率暴击；5 级可通过职业之证解锁嘲讽 | 伤害、暴击率、身板及具体成长 |
| 盾骑士 | 偏重生存，物理输出较低；默认被动有概率格挡物理直接攻击；职业技能为存活队友加盾 | 格挡与群体护盾数值、成长；法术格挡留待后续升级方向 |

### 战士的嘲讽

嘲讽针对本次连线对应的目标。技能可以不限距离，战士的物理攻击仍受自身射程限制。因此，在技能满足施放条件时，可以连接远处敌人的端点只做嘲讽，不凭空造成近战伤害。

**本次攻击击杀所连目标时，跳过嘲讽，不启动该次嘲讽 CD。** 目标存活且技能满足解锁、CD、射程和目标条件时，自动施放嘲讽。跳过施放不启动新的冷却，不在此规定已有冷却如何减少。

持续时间为**本次行动后的一个敌方阶段**，阶段结束即失效，不依赖敌人是否真的出手。敌人只有在战士存活且属于自己可攻击的合法目标时才转向战士；否则继续选择可攻击目标，不会为了攻击后排战士永远停住。

这使嘲讽成为有风险的保护：战士血量不足时，玩家可以换其他成员出手，或使用盾骑士提供保护。

### 盾骑士的护盾

盾骑士出手时，在技能满足解锁、CD、射程等可用条件以及存活队友目标条件时，自动为所有存活队友提供护盾，覆盖紧接着的敌方阶段，之后到期。**本次攻击击杀所连目标，不会因此跳过护盾。** 只在真正替队友挡住伤害时体现保护贡献，未消耗的护盾不会被当作已承受伤害计入战后成绩。

### 自动施放与冷却的确认边界

2026-09-15 用户在架构任务确认：继续采用选角色、连线后自动攻击与释放技能；战士击杀目标后省去嘲讽及该次 CD，盾骑士击杀后仍按技能条件加盾。技能冷却的存在及各自独立的冷却状态已确认。此判断按职业技能分别定义，不能推广成所有职业统一“击杀就不放技能”；法师、弓箭手等其他职业的具体技能之后单独讨论。

**架构任务已向用户说明的执行口径：** 先结算本次攻击的真实结果，再判断当前职业技能；不使用遗漏暴击、减伤等实际结算的预估伤害代替结果。技能实际施放才启动新 CD，跳过嘲讽不启动新 CD。当前战士、盾骑士的自动技能处理完成后，再检查整次玩家行动是否获胜；盾骑士击杀最后一名敌人也不另加“自动省盾”规则。没有实际吸收伤害的护盾不增加保护贡献。这是架构任务同步的执行解释，与上述用户确认的玩法决定分别记录。

**后续已确认：CD 按全队有效行动推进，相当于按回合数冷却。** 一次有效连线及其敌方阶段构成一轮，双射第二发、毒伤等子效果不额外增加回合；思考、无效画线、广告与菜单操作不推进 CD。各技能仍分别记录自己的剩余冷却。

**开场可用、施放当回合不立即减少新 CD 已确认。** 新施放技能从之后的完整回合结束开始递减；例如施放后显示 2，下一名队员完成一次行动及敌方阶段后变成 1，再完成一轮后变成可用。例中的 2 仅用于说明计数，技能正式 CD 数值仍待配置。其他职业的自动施放条件继续按对应技能明确。

系统自动处理消耗品与技能，省去对已死亡目标没有作用的追加消耗及技能 CD；普通攻击的双射表现仍保留。判断依据是对应效果的有效目标与规则，不把“主目标死亡”推广成所有技能都取消；盾骑士群盾仍沿用已确认条件。活目标已经中毒时，继续使用毒箭仍扣数量并刷新持续时间。

### 法师与持续毒伤

法师首个专属采用“爆裂火球”：爆心为主目标的固定原阵位，左右各取一个原阵位。敌我死亡后整面留空、不补位；不能因上一轮已有死亡空档而越过它找更远活敌。本次普攻击破中心后，仍对活邻位结算；中心伤害与周边伤害独立配置，死亡中心不向邻位转移伤害。三个位置都无有效目标时省技能。火球 CD 先用 2，伤害倍率仍待统一校准。奥术穿透只由普通法术命中触发，火球与持续伤害不再触发。火冰伤害、克制与烧伤按敌人材质分别配置，暴风雪及具体冰技能留给后续内容。弓箭手丛林束缚只在所连前排目标存活、可被束缚且下一敌方阶段确实攻击时施放，取消这次攻击并让敌方行为序列正常前进，不延后循环重砸。

毒箭采用三次毒伤结算，烧伤采用两次；全场持续伤害在敌方阶段前统一跳一次，再处理死亡和存活敌人的行动。玩家本轮新施加的状态可在紧接的这个时点跳第一次，敌方行动中刚施加的状态到下一次统一时点才跳。同类刷新次数、不叠层，强度不同时保留较强伤害；毒和烧伤可并存。已中毒目标继续消耗毒箭并刷新。具体伤害量由配置表制定。

同一时点的毒、烧伤超过目标剩余生命时，按各来源本次生命伤害的比例分配有效贡献。例如剩5生命、毒4和烧伤6，实际贡献分别为2和3；剩1生命、伤害1和2，则保留精确的1/3和2/3，不逐项取整或按播放先后抢占。先算各来源份额，再归到施加状态的角色；同一时点形成全场结果后再处理死亡。此规则以无护盾或各来源扣生命伤害已有定义为前提，不顺带决定共享护盾的分摊，也不增加额外击杀分。

毒伤在后续回合致死，或 AOE 波及非连线目标致死时，都没有本次连线可以固化；最初施毒的临时线可能已经消失并被后续固化线占用，不能事后强行恢复。

用户后续已选择：毒伤和 AOE 可以致死，当前正常回合结算后通过不消耗攻击回合的手动画线完成路线固化；必须补完再进行下一次攻击，清场后也须补完才结算。此前“最低保留 1 点生命再连线击杀”的建议不采用。具体免费补线规则见第 03 节。

属性克制与异常状态分开表达：植物类可受火属性克制并被火球烧伤；金属类不会被烧伤，但这不等于对火球的直接属性伤害免疫。不同敌人分别明确属性弱点/抗性、可以附加的状态与状态免疫。冰系不会仅因具有冰属性就默认冻结所有目标，具体附加状态须随技能确定。

棋盘配对颜色仍表示敌人身份，不改成火系一定红色、冰系一定蓝色。弱点、抗性及烧伤/中毒用对应图标表现，避免破坏端点配对识别。烧伤伤害和持续时间、火冰相互作用与状态图标优先级尚未定。

首章上弦小工每次恢复活的绑定目标最大生命的10%，保留小数并按实际缺血封顶；只有实际恢复大于0才消耗一次。满血或目标死亡时保留次数、空过这次上弦意图，不临时改攻击、不复活或更换绑定；次数耗尽后沿原行为表。普通关与Boss的离线算例已统一此规则，实际游戏与表现仍待初版验收。

## 07 · 随机效果的手感

暴击、连射、格挡等采用“连续未触发后提高下一次触发机会，成功后回到基础状态”的伪随机方向。它用于减少长时间不触发带来的挫败，不代表新增普通攻击未命中的规则。

不同角色、不同被动各自积累触发机会。重演完全相同的一段行动应保持一致，撤销不成为无限重抽暴击的方法。

PRD 生命周期已确认：新战斗重新初始化；本场死亡和广告复活保留积累，广告本身不抽取结果；撤销恢复对应历史中的随机状态和积累，重来恢复本局入场状态；普通战术物品换装不清空角色固有被动积累。

被动触发概率是升级属性之一，纳入各职业成长。具体等级概率、成长曲线及效果强度仍待制定；不能把所有职业都默认加上暴击，也不把早期 50% 暴击和概率数列当成正式配置。

**双射触发后，普通攻击仍打两次。** 第一发已经击杀时，第二发仍产生对同一目标的溢出伤害及反馈，不自动转火另一敌人；第二发不对死目标消耗毒箭、推进其他被动或施放无效技能。仍是一次玩家行动，不重复固化路线、发击杀奖励或增加有效伤害评分。双射只追加一发，不递归触发自己；追加发对活目标照常判命中、物理格挡和毒箭消耗，不自动获得暴击能力。

溢出反馈方向：第一发击杀后保留短暂受击残影，第二发击中时让端点和同一条线路再闪击一次，配合碎片或冲击环；随后完成固化收势。保留伤害数字的表现，但不让尸体伤害增加有效贡献。具体动效尚未制作或确认。

**首版格挡针对物理直接攻击，不格挡法术或中毒持续伤害。** 毒箭的物理命中部分按物理格挡处理，后续毒跳伤不再判格挡或闪避；普通护盾可吸收直接伤害和毒、烧伤，但不阻止施毒本身。

用户明确中毒不影响角色原有格挡能力；施毒这类特攻只能通过闪避避开，不能靠格挡阻止施毒。随后确认闪避发生在施毒攻击到来时，已经中毒后的持续跳伤不再判闪避。角色的闪避来源、概率及哪些攻击可闪避尚待补齐，不能自动给所有角色配置同一闪避率。

暴击只由本身具备暴击能力的直接命中判定，战士每次真实命中判一次；闪避后不再抽命中类被动，格挡仍算命中。首版毒、烧伤与火球不额外判暴击，弓箭手双射不会自动获得暴击能力。具体概率和成长由配置校准。

## 08 · 撤销、重来与退出

撤销采纳与棋盘对象关联的操作方式：从端点或已固化线路定位想撤回的行动。**恢复到该行动提交前，并一起撤回它之后的全部玩家行动和敌方行动。**

例如：第 1 次出手击杀 A，第 2 次攻击 B 未击杀，第 3 次击杀 C。若撤销击杀 A 的行动，就回到第 1 次出手前；B、C 的后续战斗也一起撤回。不能只拿走 A 的线，却保留依赖它发生的伤害和收益。

回退包括线路、生命、倒下状态、护盾、嘲讽、中毒、敌方意图与待结算战斗收益，并保持随机结果的一致性。

交互落点建议：点击端点定位对该目标最近一次出手，点击固化线中段定位该次击杀。点按与开始拖线如何区分、是否显示回退范围预览，保留为交互细化项；“连同后续完整回合一起回退”的规则已经接受。

重来就是从头重新开始本局，不保留本次尝试的战斗进度或失败收益。退出始终可用。局外已经获得的等级、物品和现实时间经过不属于战斗历史。

**R02 原入场重来解释已签收（2026-09-17）：** 立即重来回到第一面，沿用本次最初入场的参战成员、站位、战斗属性与生命、携带量、配置和随机／PRD初态。本次倒下不先转成局外恢复，不新增等待或广告门槛。永久成长、已学技能、已确认用卡、广告事实和当前道具开关仍保留；原有局外恢复按真实时间继续，恢复完成的原未参战者不会自动加入本次阵容。退出地图后重新入场，才读取最新成长、阵容与可出战状态；重来不回退永久资料。

**已获得的广告权益不会被撤销收回。** 已获攻略仍可查看，已经领取的广告资源不因撤销减少。回退到复活前时，那次权益恢复为该角色可直接使用的一次满血复活；角色活着时不强行补血，倒下时显示发光心形与小勾，点用不再看广告。没有回退这次复活使用、只是后来又倒下时，需要新的广告。未使用权益重来或退出也保留，可用于该角色后续一次局内复活或局外恢复。

- **缺法师的独有固定卡经验保留。** A独有的广告卡已经给法师产生固定经验，而所选B尚未正常获得同源法师时，保留这笔经验，等B正常获得法师后追加一次。不提前解锁，不退卡、改给其他角色或导入A的普通进度；不复制A的等级、技能与恢复状态，不再套评分或结算倍率。此情形须能核验同源身份、准确卡来源与兼容规则，不能套在上一条已舍弃的同卡消费上，也不默认合并独立游客的同职业角色。
- **永久丢失时恢复准确的一次局内复活机会。** 玩家明确设备及本机存档永久丢失，且原局内复活的使用及效果仍无法核实时，在身份与准确使用记录可核验的前提下恢复原机会一次，接受它可能已经生效过。每条实际使用记录只恢复一次；之后的新使用若再次满足相同条件，独立处理。正常断网、超时、局外恢复和其他广告用途不适用。原广告事实保留，不要求重看；恢复先完成后才收到旧效果或撤回记录，不再次返还或收回已恢复机会，也不影响后续新使用。恢复机会不代表找回原战斗或已经复活角色。

原第8关广告通关整份结果在较早存档中的接入时机见第11节；它与缺法师的固定卡经验分别保留，不能混成一项奖励。

不擅自增加“每局最多复活一次”“看广告后少给奖励”等限制。

胜利后的广告增益与广告直接通关是两个不同选择。未看结算广告时照常领取正常奖励；结算入口先展示增益，不自动播放。五档 2.0、2.2、2.5、2.8、3.0 的首轮概率采用 35%、25%、20%、15%、5%，随机停针，连续数量的期望倍率为 2.32。材料和经验卡均先合并本次同类数量，再乘倍率向上取整；具体经济平衡仍须验证。

用户已接受奖励范围：经验、经验卡及普通材料乘倍率，职业解锁及 Boss 首通职业之证不倍增。材料向上取整已确认。广告直接通关和后续结算增益可以作为两项自愿选择，不能自动连播两次广告。

## 11 · 免费默认攻略与在线剩余步骤

玩家点击右上角提示，直接打开默认攻略动画小窗，下方棋盘同步演示全部走线；上方仍是实际战场，不预演攻击或技能。未击杀时参考线消失，击杀参考线保留，免费补线也纳入顺序。结束保留总览并允许重播；玩家第一次开始画线后收起两处预览。预览不改变实际生命、道具或回合。

**看广告用于联网 AI 分析当前局面，给出剩余完整通关步骤。** 一次广告解锁本次挑战的解析与后续更新，包含重来及退出后继续，直至通关。已获得的攻略不受撤销影响，通关后也能回看；重新挑战时，默认攻略仍免费，新的在线分析使用新挑战的服务权益。

入口方案为默认攻略小窗中的轻量“解析当前局面”按钮，广告角标只标识这个在线入口。查看默认攻略不会消耗次数，也不会把主提示图标变成收费入口；已有在线权益时按钮直接用于解析。此处替换历史“免费提示用完后整个提示入口显示广告”的口径。

### 背包堆叠与自动整理

背包不限制总格数，可堆叠物品每叠上限统一为 99。同类物品合并成满叠及最多一叠余量，避免多个格子分别散放两把、三把同类物品。背包自动合并，也提供“自动整理”按钮供玩家主动操作；整理不改变总数量。每名角色的战术槽携带一叠，出战前从现有库存尽量补到 99 个。

例如：角色剩 2 把飞斧、背包有一叠 99 把时，下次优先携带 99 把，余下 2 把归入背包；背包里的 60、50、7 把可合并为 99、18 把。库存不足满叠时携带现有数量。

合成采用固定配方，首版材料用于制作职业专属消耗品。永久装备及其强化留到后续版本。

### 背包与合成目录

背包采用“物品 / 合成”双页签，先浏览目录，再点开单项详情。物品按全部、战术、材料、成长分类，战术物品和配方可按职业筛选；支持按名称、用途查找，配方也可按所需材料查找及只看当前可制作的内容。

角色详情按成长、技能展示主要信息。点击“使用经验卡”后，在当前手机画面内打开升级弹层，背景角色页压暗，不向下扩展页面。弹层同时显示上下滑动的目标等级滚轮、消耗预览、“可升最高”和确认按钮。选中等级以柔和圆形光晕突出，替换两条横线，是本轮待审阅的视觉方案。关闭或点击背景不扣卡；确认后扣卡、收起弹层并更新角色，多出的经验保留。达到 5 级后单独使用职业之证解锁，不自动消耗。战前点击敌人查看意图、弱点与免疫，并附简短的应对建议；沿用阵容直接开战不受影响。

## 13 · 评分经验：让每个职业都能表现

最终采用每个角色独立计算的公式：

**角色经验 = 关卡基础经验 × 该角色等级修正 × 该角色评分倍率。**

不按最后一击分配，不把整队经验放进固定池竞争，也不因高等级队友加入而统一削减低等级新人的经验。角色自身等级明显高于该关推荐等级时，其基础收益下降；低等级角色按自己的等级和实际贡献计算。

| 贡献 | 怎么体现 | 不计入的虚假增量 |
| --- | --- | --- |
| 输出 | 有效伤害、克制击杀、少量行动解决关键目标 | 对已不足血量目标的全部溢出伤害 |
| 保护 | 实际吸收的护盾、格挡减伤、有效保护队友 | 没有挡到伤害就到期的护盾 |
| 恢复 | 实际补回的生命 | 满血时的过量治疗 |
| 辅助 | 实际改变战局的嘲讽、控制或削弱贡献 | 反复施加却未产生作用的状态 |

评分累计不设硬上限。玩家愿意长时间打同一场，可以继续积累真实贡献；倍率随评分提高而增长，但增长逐渐放缓，避免增加一点可重复贡献就无限线性放大奖励。

持续伤害的贡献继承第06节同一时点的精确比例份额，汇总到原施加者后再计分；不把分数先取整。经验只在既定整数奖励出口向下取整，已形成的固定广告结果不重新评分。

此前用于解释曲线的“100 分约 1 倍、400 分约 2 倍、900 分约 3 倍”只表达递减增长形状。最终基准分、各职业权重、等级衰减函数、零贡献与低贡献收益仍未定稿。

玩家的思考时间不扣分。平衡时要同时看单关收益和单位实际游玩时间的经验：高等级角色清低关更快，仅降低每关经验不一定足够。普通关约 15 秒是节奏目标，不是评分倒计时。

## 14 · 战后亮眼时刻

胜利后先让玩家看到“我做得很好”：三名队员的卡片、各自经验变化、关卡掉落，以及一个与真实表现对应的亮眼角色。

表现示例：盾骑士卡片稍向前抬起，头像做举盾动作，短促光波散开；标题出现“可靠守护”，副文案说明实际为队友抵挡的伤害。输出角色可以表现为挥剑收势、收弓等职业动作，不必所有角色都用伤害第一名争夺奖励。

<!-- demo:victory -->

亮眼动画初始观察时长约 0.9 秒，可与经验条增长同时播放。“下一关”立即可点，详细统计折叠起来供感兴趣的玩家展开。动画不成为连续过关的固定等待。

本案示意用职业符号表现卡片节奏；正式 Q 版角色需要制作相应动作。示例中的伤害、经验、掉落、升级进度和称号文案均为展示数据，没有用这些数字宣告平衡已经完成。

## 15 · 第一段冒险与评审场景

开局战士，第 8 关获得法师，第 14／15 关普通复习备战，第 16 关首次入场战前赠证并确认学嘲讽，整场首通再给第二枚通用证；盾骑士第 21 关、弓箭手第 37 关。Boss 第一面全部敌人及线路完成后翻面，我方生命、倒下状态、道具、CD 与持续状态延续，最终只结算一次。普通关逐渐教会同色连线、未击杀消线、击杀占格、职业差异、射程前移与敌方意图；第 6～8 关递进物抗，第 9 关用新法师体现优势。

以下是制作试玩版时应能展示的体验场景，不是新增的程序实现方案：

| 场景 | 应看到的结果 |
| --- | --- |
| 战士攻击远处目标，只有嘲讽距离可达且技能可用 | 可连线，只出现技能反馈，没有攻击伤害 |
| 战士本次攻击实际击杀所连目标 | 跳过嘲讽，不启动该次嘲讽 CD |
| 战士攻击后目标仍存活，嘲讽满足施放条件 | 自动嘲讽所连目标，实际施放后启动新 CD |
| 预估未击杀但暴击等真实结算击杀目标 | 按真实结果跳过嘲讽，不能按预估误放技能（架构执行口径） |
| 盾骑士本次攻击击杀目标，护盾满足施放条件 | 仍自动为存活队友加盾 |
| 盾骑士击杀最后一名敌人，护盾满足施放条件 | 先完成自动护盾再检查胜利；未吸收伤害不加保护贡献（架构执行口径） |
| 战士在后排嘲讽近战敌人 | 敌人不会永久等待；按合法目标行动，嘲讽按时失效 |
| 敌人 A 倒下 | 射程 2 从 A/B 更新到 B/C |
| 对同一敌人一次未击杀、一次击杀 | 前一次线消失，后一次线保留；端点两次都参与重击 |
| 画出合法但堵路的固化线 | 接受失败可能，撤销或重来可恢复尝试 |
| 撤销早期攻击 | 之后的敌我行动与相关收益一起回退 |
| 第二次发生队员死亡 | 保留灰色 XX 头像，不重复第一次的飞字教程 |
| 只有一名队员倒下 | 广告图标仍先展开菜单，让玩家明确选择 |
| 高等级角色带低等级新人刷旧关 | 两人的等级修正分别计算，贡献各自展示 |
| 盾骑士完成关键保护 | 战后可以成为亮眼角色，不能只认最高伤害 |
| 广告直接通关 | 正常通关、解锁与掉落；经验直接给关卡基础经验，不套评分倍率 |
| 已选三名成员中一名仍在恢复 | 上方阵容显示该头像的恢复状态，其余两人允许出战，不重复增加人数提示 |
| 弓箭手触发双射，第一发已经击杀 | 第二发仍产生溢出伤害及反馈，不向死目标消耗第二支毒箭；只固化一次、有效伤害评分不增加 |
| 盾骑士受到物理直接攻击、法术或毒跳伤 | 仅物理直接攻击适用首版格挡；护盾与毒的关系另定 |
| 角色本场连续未触发被动后死亡并广告复活 | PRD 积累保留；重来恢复入场状态，新战斗重新初始化 |
| 玩家正常胜利后不选择收益广告 | 仍领取正常奖励；可选广告倍率五档 2.0～3.0，覆盖经验、经验卡与普通材料 |
| 毒或 AOE 杀死没有本次线路的敌人 | 敌人死亡，提示手动补线；补线固化占格，不消耗攻击回合、不推进 CD、不产生敌方行动或重复收益 |
| 敌人在其战斗行动前被毒死 | 跳过该敌人的行动，其余存活敌人照常处理；正常回合结束再免费补线 |
| 已中毒目标再次受到毒箭 | 仍扣这一支毒箭，刷新持续时间，不累加为双倍毒伤 |
| 点击默认提示，再开始第一次画线 | 小窗和棋盘先同步播放连线动画，开始画线后一起消失，不先弹选项列表 |
| 火球命中植物类与金属类敌人 | 按各自火属性克制/抗性结算直接伤害；植物可烧伤，金属不被烧伤 |

普通关 15 秒、Boss 60 秒仍须通过真实玩家和 Android 设备验证；每场新增的准备动作也计入预算。当前尚未有这款 RPG 的可玩版本或设备测试，不能把表现演示的流畅度当成游戏性能证据。

## 16 · 已定、待调与下次联合梳理

**已定的骨架：** 每职业一名角色，开局按战士安排，后续职业第 8／21／37 关解锁；最多三人、独立血量、允许少人出战；有效攻击连线一次行动；未杀消线、击杀占格；毒和 AOE 可致死并免费补线，端点采用图形提示；攻击与技能分开判距离；按职业自动施放，CD 开场可用、随全队后续回合推进、施放当轮不减；战士击杀省嘲讽、盾骑士仍按条件加盾；法师爆裂火球、火冰属性与敌人种类的状态差异；双射保留溢出反馈、省无效消耗；物理格挡、施毒攻击可闪避但毒跳伤不可闪避；持续伤害在敌人战斗前结算，毒刷新且仍耗箭；PRD 生命周期与概率成长；完整历史撤销且不收回广告权益；5 级加职业之证解锁，Boss 首通送 1 枚；评分经验；不限次单人满血广告复活；默认提示直接同步动画；广告通关给基础经验，结算广告增益另选。

**待调的数值：** 生命与伤害、角色射程配置、被动概率、技能效果量与 CD 数值、敌人行动频率、等级成长、评分权重、经验修正、掉落表、局外恢复时长。3 分钟恢复、15/60 秒战斗和 0.9 秒亮眼动效均为初始目标或演示参数。

**原三组缺口已收口，后续工作：**

1. 内容与数值校准：统一第 8 关法师入队后的首章敌人、成长、掉落、技能效果量和配方，复算已接受 CD、广告概率与整数奖励；确定后续主题的具体内容表。由策划提交结果，不要求用户逐个提供数值。
2. 表现评审：最终画风和真正的拔武器、换站姿、Boss 慢姿态、受击与翻面样本仍需比较。经验卡和目录等交互方向保留；旧示意不等于正式动作或 Android 测试。
3. 联合复核：把本稿、内容任务产物与独立讨论的架构对齐，核对完整回合、免费补线、跨面撤销、广告权益以及在线攻略验证。联合复核结束后再确定下一阶段，不在此启动游戏实现。

首版核心玩法不再列一轮泛化问答。未定的绝对数值与视觉细节由方案和样本驱动；真正出现冲突或影响体验的取舍时再集中讨论。
