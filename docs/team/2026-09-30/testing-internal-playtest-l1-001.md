# 首个新 uGUI Android 内部试玩：最短 L1 验证清单

2026-10-01（Asia/Shanghai） · QA-001 · `PREPARED_NOT_AUTHORIZED_TO_RUN`

本清单复用 `planning.md` PQA-01／02／10／12／14／15、
`engineering-system-001.md` Q6／Q7、`engineering-android-api24-001.md` 与
`engineering-android-graphics-001.md`。它只准备首个同源 API24／GLES3 normal APK 的
内部试玩，不新增大型测试方案，不授权现在构建、安装、清档、启动 Unity／ADB 或操作设备。

## 1. 运行前绑定

执行回执必须先固定：源码／资源 candidate、uGUI／LAYOUT／API24／GLES3 的独立接收身份、
normal APK path／bytes／SHA-256、package／version、证书摘要、构建报告、设备或模拟器的
品牌型号／Android／API／ABI／GPU renderer，以及执行者 thread／host／turn。必须由普通 launcher
图标启动；不得使用 `-force-gles30`、`-force-vulkan`、`--es unity` 或其它启动覆盖。不得用旧
019 APK、旧 UI Toolkit 画面或 EditMode 结果替代本候选。

若仅有 BlueStacks，结果只能作为内部模拟层回归；不得替代 iQOO 或另一台真实 Android 的最终
设备门。资料根必须是明确的合法 QA 资料；需要空档时只创建新的受控测试资料，不清除既有玩家
资料，不以卸载重装掩盖恢复问题。

## 2. 一条最短真实流程

1. **图标冷启与建档**：先保存本应用相关日志起点；force-stop 后由普通图标启动。确认进程／
   Activity 稳定至少 30 秒并到达新 uGUI 初始页；在空 QA 资料上创建且只创建一份资料。核战士
   Lv1／XP0、另两槽为空、库存为空、进入地图、无诊断占位符。
2. **语言切换**：在地图或设置承载页完成当前语言→另一语言→当前语言一次往返。每次核当前页
   与重建页同语种、动态参数与中文字形完整、无混语／截断／占位符。最终停留在另一语言，供
   后续冷启动检查记忆；系统语言首次映射的另一分支留给最终验收，不为本次最短链重置系统。
3. **进入 L1**：从地图自然进入 L1，选择唯一战士并确认正式入场。核没有假角色、假下一关、
   假配方或额外奖励；棋盘、HUD、按钮和安全区可见且不互相遮挡。
4. **活动局恢复**：完成至少一次真实合法触摸连线后记录当前局面；Home→恢复一次，核原进程或
   Android 合法生命周期恢复、原局仍在、没有重复提交。随后 force-stop，再由普通图标冷启，核
   语言选择仍记住、恢复同一活动局且未生成第二局。
5. **完成与结算**：按产品内已发布的 L1 默认参考逐步人工触摸，不调用参考回放或业务接口代替
   提交。胜利后核先保存、再完成或明确跳过最后播放、再由玩家点击继续基础奖励结算；只入账
   一次 20 XP 与 2 锡片。结果页的地图／队伍／背包／合法重打入口可见，无下一关事实准确。
6. **结算后冷启**：记录结算后的等级／XP／库存／原结果；force-stop 后再次由普通图标启动。
   核同一资料、已结算状态或合法结果入口恢复，20 XP／2 锡片未再次入账，语言选择仍保留。
7. **返回与退出应用**：至少在一个子页用系统 Back 返回合法上一页；在根页触发退出应用确认，
   先取消并核上下文不变，再确认。不得把退出应用冒充退出本局。

任一步出现不可自然完成的 L1、重复奖励、活动局复制／丢失、占位符、混语／缺字、触摸路线与
命中不一致、黑屏、native crash／ANR、恢复到错误页面或必须依靠启动覆盖，立即保存现场并停止，
不得注入胜利、清档、换 APK 或临时改设置求绿。

## 3. 最小证据集

- APK／源码／资源／包名／版本／证书及构建报告身份；设备事实与执行时区／时间线。
- Cold、Home/Warm、活动局 Relaunch、结算后 Relaunch 各自的 PID、Activity state、应用相关
  logcat、exit-info；完整日志必须覆盖 Unity renderer/device 初始化，实际为 OpenGL ES 3，且无
  Vulkan 初始化、graphics override、native crash 或 ANR。
- 一段连续屏幕录制覆盖图标冷启→建档／地图→入场→至少一次真实触摸；另保存活动局恢复、
  胜利待结算、结算结果、结算后冷启、两语言同一代表页与退出确认的带时间截图。
- 结算前后及结算后冷启的可见业务事实：等级／XP、2 锡片、同一活动局／原结果标识；只记玩家
  可见稳定事实，不把 OperationId、CommitId 或内部诊断值当产品文案。
- 每一步填写 `PASS`、`FAIL`、`BLOCKED_ENVIRONMENT` 或 `NOT_RUN`；缺日志、缺截图、缺候选身份、
  缺真实触摸或中途换包均不能补写为通过。
