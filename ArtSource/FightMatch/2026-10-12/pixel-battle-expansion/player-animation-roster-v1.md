## 共同制作契约

- 128×128 RGBA；最多 16 个不透明颜色；alpha 仅 0/255；3/4 朝右。棕色刺发、青绿上衣、米裤、红围巾、短剑、棕金圆盾的身份不变。最近邻预览。
- 复用 `references/character-scale-profile.json`（逐字节复制自 Initial 01），每个兼容动作使用同一份 profile。当前 profile 的处理策略是 `fit`、输出 origin `[64,117]`；最终已接收像素的脚底是 `y=115`，两者不是同一个指标。后续必须同时核处理元数据和最终像素，不能把 origin 117 当成新的落脚线。
- 本表锚点 `G`：画布根 `(64,115)`，共同脚接触线 `y=115`，与 Initial 01 对齐。步态允许摆动脚离地，支撑脚落回该线；画布根不随 bbox 漂移。`R`：倒地仍保留同一地面根与世界位置，不因人物横卧而重新 bbox 居中或放大。下文均为源图左上原点坐标，不是 Unity pivot 配置。
- 生成时固定头、躯干、四肢、剑盾的解剖尺度和相机距离；攻击姿势的剑保持在安全范围。自然蹲低/倒地不等于缩小角色。若现有 fit profile 因出剑姿势缩小人物，应先重做生成构图；确需改 profile 策略须交主美确认兼容方案，不能给每个动作另设放大率或覆盖现有基线。
- 未来高价值主角的 grounded（有地面支撑）动作，必须用同一已接收首帧制作 character anchor sheet（角色锚点图）。每个动作独立采用多行网格；生成前实际展示已接收母帧和该动作的锚点图，让母帧锁定身份，让锚点图锁定格位、相机距离、站立等效解剖尺度、root、脚线与安全留白，只允许动作姿态变化。后处理继续复用现有 profile，不以锚点图替代 profile 或逐动作另定缩放。倒地、击退、腾空等根位置或姿态显著变化的动作，不机械套用站立锚点模板，需按其运动轨迹定义根与留白并独立检查。本次只补制作契约，没有生成锚点图或玩家动作。
- Body 包含身体、衣物、盾、实体剑及剑鞘；FX 独立生成独立验收，包括宽剑光、命中、尘土、技能提示。无 FX 也应能读懂动作。不要用整体缩放/旋转/上下平移替代头、躯干、手臂、腿及武器的动作。
- 剑鞘位置和收剑手型须在未来首个收剑静帧中与现有腰带、持剑手核对；本包不重新设计或改动 Initial 01。抓柄、剑刃离鞘、换握、警戒的手—柄—刃关系必须连续。

## 动作与建议规格

表内顺序就是建议生产次序。每行动作分别用 image_gen 生成，再各自清理、QC；不得将这些不同动作塞进一张原始 AI 图集。4 帧用 2×2，6 帧用 2×3，8 帧用 2×4；确需引擎横条或混合图集，只在所有单动作验收后确定性拼装。

混合动作会让逐格角色身份、相机尺度和动作连续性更难保持；宽武器或 FX 还会拉大 bbox，迫使身体缩小。单动作网格可以独立 QC 和重做，不损伤其他已接收动作。

生产分组：先锁定 1–2 的出鞘衔接，再做 3–5 构成基本战斗反馈；6–8 扩充三种攻击与嘲讽；9–10 补结束状态；11 根据实际入退出场决定。敌人本次只做静态候选，用户选定后才可能进入另一个 6 帧 Idle 制作包。

## 开场及中断语义

`draw_ready` 的 8 帧建议时长为 `140/100/100/80/110/110/80/80 ms`，合计 800 ms：前 140 ms 放松及伸手，140–420 ms 抓柄/离鞘，420–640 ms 站稳架武器，640–800 ms 收势。所有秒数仍为体验候选，需后续试玩。

普通关实际参战角色并行准备，不能按人数串行加长。准备不攻击、不扣血、不耗道具、不推进 CD、PRD 或敌方阶段；完成并能读到首个意图后才开放操作。同场画线、撤销、复活、Boss 翻面不重播准备。攻击、移动、技能、受击恢复都回持剑战斗 Idle。

Boss 约 3 秒开场包含这套准备，不再额外叠 0.8 秒；察觉、抬头、受震及重新架武器是以后需单独审批制作的衔接，不能用强行切 Idle 冒充。本清单不制作 Boss、法师或这些附加动作。

## 每个未来动作的验收

1. 先看无 FX 的关键姿势：松弛/抓柄/离鞘/警戒，以及横斩/前刺/下劈各自能静帧辨认；手、剑、盾连续，无黑色断口。
2. 128×128、最多 16 色、二值 alpha；头、脚、武器、围巾完整，output edge touch / paste clamp / empty frame 都为 0。
3. 与 Initial 01 并排检查头身尺度及落脚线；兼容的站立动作按共享 profile 的 10% 漂移上限检查，目标更严格可取 8%。脚根不漂移；倒地真实姿态压低不强行缩放成站姿高度。
4. 地面人形多帧动作 body_scale_cv ≤0.08、normalized anchor_y_std ≤0.05 作为生成检查；倒地等姿态变化另看根和关节，不能用逐帧缩放伪造通过。
5. 循环首尾和一次性动作进入/退出需同尺度对比；至少查看原尺寸、6×浅底、深底及透明预览。播放 timing 候选必须保留，不以帧数推定正式命中时点。
6. 每动作独立保留 raw、prompt、可编辑源、帧图、预览、处理/QC记录。先专业接收，再开 Unity 接入与设备验证包；本文件不修改状态机、玩法和存档。
