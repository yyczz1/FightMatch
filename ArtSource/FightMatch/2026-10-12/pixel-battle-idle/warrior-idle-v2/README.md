# Warrior Pixel Battle Idle — Initial 01

Status: `INITIAL_BASELINE / USER_ACCEPTED_AS_FIRST_PASS / NOT_IMPORTED`

这是对 Candidate 01“整体上下平移”问题的重做版。角色不再把整张身体当作一块上下移动；六张关键姿势保持同一落脚线，通过轮廓与局部姿势变化表达吸气、峰值、呼气与回稳。

## 动画设计

- 角色：棕色刺发、青绿色上衣、米色长裤、红围巾、短剑、棕金圆盾。
- 视角：朝右的 3/4 战斗待机姿势。
- 画布：每帧 `128 × 128 px`，六帧共用 `y = 115` 的最下落脚线。
- 循环：6 帧，逐帧时长为 `260 / 180 / 220 / 180 / 260 / 240 ms`，总长 `1.34 s`。
- 节奏：静止基准 → 吸气起势 → 吸气峰值 → 短暂停留/次级部件错拍 → 呼气 → 回稳。
- 运动重点：胸腔和肩线轻微变化；头部、盾牌与围巾不完全同拍，围巾负责最后的余动；脚底与整体重心不做周期性升降。
- 像素约束：每帧 16 色；透明度仅使用 `0/255`；最近邻放大预览。
- 实现：完整逐帧像素姿势，不需要 Spine，也没有骨骼插值或网格变形。

## 检查结果

- 6/6 帧有效；GIF 为 6 帧、`768 × 768 px`、总长 `1.34 s`。
- 六帧落脚线均为 `y = 115`。
- 六帧均为 16 个不透明颜色；透明度值只有 `0` 和 `255`。
- 与第一帧比较，其余五帧均不能由 `±3 px` 范围内的整图平移得到。
- 相邻帧变化占画布 `4.71% / 5.40% / 8.98% / 8.12% / 6.42% / 6.11%`，变化不是单帧复制。
- 严格提取 QC：边缘触碰 `0`、粘贴截断 `0`、角色高度均值 `104 px`、体型尺度 CV `0.00335`、脚锚点 Y 标准差 `0.00149`。
- 浅色背景预览已用于人工检查手臂、持剑手、腿、盾牌与身体连接；未见此前黑色矩形断口。
