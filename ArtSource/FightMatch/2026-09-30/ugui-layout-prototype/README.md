## 4. 页面、弹窗与文字容量

总览覆盖当前 L1 所需：

- 启动／本机资料：四行诊断容量与最多三个纵向动作；
- 地图、队伍、背包三主导航：L1、真实空槽／空态、活动战斗原因和返回入口；
- 入场：L1、阵容、四行诊断、确认或继续原战斗；
- 结果：基础奖励、L1 结束说明和地图／队伍／背包／重新入场四去向；不显示首通额外奖、广告倍增或下一关；
- 战斗默认参考：参考线只落在真实棋盘，`ReferenceInfoDrawer` 替换 BottomHud、不盖棋盘；真实拖线开始时 Drawer 与参考线立即让位；
- 普通确认：正文独立滚动，标题与动作保持可见，取消为安全默认；
- 保存恢复：完整 `SystemLayer` 页面，当前头／原请求／候选／错误／安全下一步齐全；动作默认全宽纵排，危险动作独立分区；
- 退出应用：明确保存状态，且与退出本局语义分开。

文字容量规则：

- `1.35×` 仅是英文相对简中的最低留白起点，不是固定按钮宽度；
- 长英文动作默认全宽纵排，高 56／64，可换两行；保存恢复与移动数据动作均按此画法；
- 普通长正文视口至少容纳五行英文；游客不可恢复确认约六行；超出时只滚正文；
- 玩家可见 Prefab 文本仍须使用明显诊断占位，图中英文标签仅为验收说明，不是正式文案。
