# L1 首批美术检查与后续批次

状态：`FIRST_STATIC_BATCH COMPLETE / REVIEW PENDING`

## 1. 逐张目视检查

### 发条庭院背景

- 上方战斗台与下方草坪棋盘层级清楚，远景钟楼、纸片云和齿轮风车建立主题。
- 角色左右站位区基本干净，暖光方向明确；棋盘草纹较轻，适合叠加高饱和端点和线路。
- 待评审：远景中央钟楼是否过强；草格数量只是画面纹理，不能与真实关卡格数绑定。
- 风险：原图 2:3，而当前 UI Toolkit 参考分辨率为 9:16；导入时应先验证中央安全裁切，不拉伸。

### 战士站姿

- 全身、双脚、盾、剑鞘和持柄手完整；朝右，能与右侧敌人形成对峙。
- 青绿／奶油／珊瑚围巾在背景上有足够色差；英雄表情友好，适合 L1。
- 当前是拔剑前的放松备战静帧，不是战斗待机或攻击帧。
- 待评审：脸部年龄感、胸前百合形图案和盾牌纹样是否要继续保留为阵营标记。

### 发条步兵站姿

- 全身、长矛、脚与背部发条钥匙完整；朝左，圆帽、锡壳和黄铜轴清楚。
- 短壮比例与战士形成敌我差异；面部是玩具式敌意，不偏恐怖。
- 当前长矛和钥匙增加横向占幅，正式小尺寸排布需留安全间距。
- 待评审：做旧划痕是否应减弱，以更贴近“明亮新玩具”还是保留少量首章磨损。

### 手机构图预览

- 战士左、步兵右均落在上方战台；敌人较矮且更宽，关系清楚。
- 棋盘没有被人物遮挡；蓝／红端点与亮线可从绿色地面分离。
- 预览中的两条路线、血条和人物二次合成细节只用于构图，不代表当前实现、合法 L1 路线或最终 UI。
- 原图为 1024×1536；最终 Android 仍需在 540×960 参考分辨率和实际安全区重验。

## 2. 建议用户本轮只评四件事

1. 战士是否像本作的长期主角，而不是过于通用的少年骑士。
2. 发条步兵的“可爱玩具／敌人威胁”比例是否合适。
3. 战场上方角色区与下方棋盘区的面积比例是否符合操作预期。
4. 奶油白、青绿色、蜂蜜木、黄铜与珊瑚点色是否作为第一章主色继续。

这些意见可决定第二批是否先做静态修订，或进入可动画分层。未收到评审前，本批标记为候选，不称最终采用。
