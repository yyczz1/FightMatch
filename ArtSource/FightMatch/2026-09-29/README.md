## 本批视觉结论

- 主题采用已定“童话玩具城／发条庭院”：奶油白搪瓷、青绿色涂装、蜂蜜木与克制黄铜。
- 战士和步兵使用相同的暖晨光、深青轮廓与柔和体积阴影；敌我朝向相对，移动端缩小时仍可区分。
- 背景把角色战台和画线棋盘做成同一件玩具地台；远景低对比，棋盘保留大面积清晰读图区。
- 预览只演示角色比例、站位、血条和两组端点／线路的可读性，不声称复现当前 Unity UI 或真实战斗状态。
